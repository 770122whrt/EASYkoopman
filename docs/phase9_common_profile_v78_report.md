# Phase 9：四构型统一设置的2秒验证（v78）

2026-09-24。v78四构型统一设置2秒验证已交付。8个MPC单元中8个完整验收；投影分支1/4个构型的综合误差低于反馈，名义物理分支1/4个。模型冻结、零训练；本轮只作短任务描述性比较，Phase9保持开放。

**结论：已有部分构型短任务收益，但这套共同设置尚未全面超过反馈。当前投影分支也不能独立证明Koopman表示贡献。**

## 辅助诊断：按MPC权重计算实际完整任务代价

下表由实际状态与命令重算，包含深度、姿态、速度、控制力度、控制变化及末端误差；四构型使用同一depth4权重。它是追加的原因诊断指标，不替换前面的跟踪误差主表，也不等于每一步局部预测代价。数值越低越好，括号相对反馈；不能据此证明局部求解达到了全局最优。
