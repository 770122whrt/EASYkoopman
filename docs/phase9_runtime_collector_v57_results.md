# Phase 9 实际采集与执行重放 v57

本轮完成实际 Isaac 采集入口、运行绑定及离线执行验收的本地实现。78项新测试包含在325项相关回归中全部通过（pytest 57.03秒）。尚未调用真实 Isaac、连接服务器或生成新的实验授权；这不是实际闭环或实时性通过的证据。

采集前核验独立的 Phase9 授权、发布包、冻结模型与实际加载源码。worker在启动仿真前完成准备；实际reset后检查质量、惯量、浮心、阻尼、控制掩码、执行器时间常数及初态，再将真实零转速初态绑定到执行历史。固定60Hz周期包含读回、决策、env.step和两次子步检查；错过周期后停止，不补发追赶。

采集入口在正常结束、异常结束和清理异常时保存实际子步、发令、回执与停止原因。清理前另存一份轨迹；若原生SDK在关闭时提前终止进程，不会凭这份中间记录通过。审阅发现缺失退出码曾可被视为零退出，新增反例复现后修复：原生退出码必须是整数，且必须为0。

新验收分两部分：

- 根据实际命令独立重算PWM、转速与推进器作用力，检查两个物理子步保持、状态/转速连续性、实际机械参数、接触/净空、支持域、时钟及完整控制周期。
- 记录计划注册、回复准入、选择/失效和使用的时钟读数；离线从真实已发命令重建执行历史，再重放仲裁。历史摘要、前缀、迟到回复、发令或激活次数被篡改时拒绝，不能只凭一个“MPC激活次数”字段通过。

仲裁重放复用原准入数学实现，没有第二套优化器，也没有重新拟合模型。物理测试使用明确标注的静止合成环境；时间值为测试夹具。它们证明记录与检查逻辑能发现反例，不能证明Isaac动力学、服务器速度或控制收益。

证据：[相关325项测试](evidence/phase9/runtime-collector-v57-checks-20260920/related01.txt)、[原生退出与耗时](evidence/phase9/runtime-collector-v57-checks-20260920/related01-native.json)、[源码与资源核对](evidence/phase9/runtime-collector-v57-checks-20260920/review.json)。早期缺少模块的失败、夹具修正及退出码反例均保留。v57累计测试墙钟151.038秒；本地阶段累计416.197/1200秒，沿用128MiB文件上限，不使用已关闭的v38预算。

当前预检草案为八构型、每构型32个控制区间，base先行；每例要求至少一次真实MPC激活，任何失败即停后续构型。worker仍为原100ms期限，低层完整周期仍为16.67ms；v56的首次100ms失败保留。该草案只验证实际接口与测量周期，不构成控制效果比较。草案尚未获新实验授权。

下一步完成有硬超时和进程清理的阶段监督程序、同一资产目录上的可执行发布包、运行说明和具体提案。随后再核验新服务器环境并进行短预检。匹配闭环比较仍须实现同优化器/同预算的名义物理、辨识物理、投影模型与Legacy/S-Surface对照，分别报告控制收益、辨识收益和表示收益。MPC2-01..04保持未完成，Koopman独特优势及Agentic增益均未证明。
