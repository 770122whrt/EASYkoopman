# 固定输入物理关系后，跨构型预测通过了新的 pilot

2026-09-12。新一轮独立数据上的结论是 **GO：可以准备正式实验**。这不是最终模型晋级，也还没有证明闭环控制或Agentic收益。上一轮自由输入矩阵的NO_GO保持不变。

## 原因、修复和结果

上一轮仅用base/uuv4训练时，Fx/m与Fz/m近乎完全共线，自由EDMD输入矩阵产生了−1125.906秒的Fx/m→垂直速度错误交叉增益。uuv6的实际水平输入超出训练范围，单步错误项最高可达4.8567m/s。问题包括输入方向缺少独立激励和缺失物理约束，不能仅归因于“模型不够大”。

本次保留TAM、PWM非线性、完整N维执行器记忆和原物理仿真，只修改预测模型：已知质量/惯量与预测推进器受力确定直接输入增量，提升状态算子学习剩余状态演化。拟合仍覆盖全部25/58维观测量，线性与非线性模型拥有相同已知物理信息。条件于同一当前状态，模型无法再学习任意的水平力→垂直速度直接交叉增益。

这里采用显式有限步长近似和逐步投影。它是结构约束的受控提升预测器；完整系统仍是非线性混合结构，不能声称全局有限维线性Koopman闭合或线性QP-MPC。

## 仍然存在的问题

- **base长时姿态仍是明确弱项。** 60步姿态原始RMSE宏平均：模型0.508803rad，persistence0.435500rad。按逐episode归一化再平均的比值为1.1385。其他通道改善使它通过了预先固定的构型综合门，但不能声称每个构型的每项指标都更好。
- 128步只预先设置了稳定性门。其总体姿态RMSE为0.316985rad，persistence为0.280161rad；该时域也没有全面精度优势。
- 仅验证3个已知目录构型、无流场/噪声/DR、约2.13秒、固定单环境。没有512步、未知真实平台、MPC闭环或Agentic实验结论。
- 未投影对照的评分全部保留。不能把已知运动学、物理输入结构和重提升的贡献全部归于线性算子。

因此本次GO只代表：继续投入正式的、更全面且有逐构型单项保护条件的实验有依据。正式实验应在新训练/验证/测试分离的数据上确认收益；若base姿态或其他逐构型检查未通过，就维持NO_SELECTION。
