# Phase 9：回退控制已实现，首次可用性检查 NO_GO

2026-09-20。新回退已经包含深度反馈、欠驱动倾斜目标和快速静态源映射，但**只有75/120次固定请求同时给出合格命令并满足周期，尚不能接入实际闭环**。本轮不调用Koopman预测矩阵，模型只提供此前冻结的fit范围；这些拒绝不能归因于Koopman预测误差。

## 已完成

[bounded_feedback_v46](../koopman/bounded_feedback_v46.py)保留原直接分配、float32 PWM正负曲线/死区和静态推力映射。新增深度比例/世界竖直速度阻尼，按当前姿态把竖直需求换算为机体heave；姿态可控时使用机体系最短四元数误差，uuv4使用竖直方向叉积误差，纯世界yaw不改变可控需求。重浮力与恢复力矩使用绑定的实际context，未声称抵消横向运动、阻力或陀螺耦合。

运行逆解最多4轮，内部10ms，保留原物理残差、PWM余量、死区余量、fit命令界及0.01变化率。启动静态逆解在READY之前准备，运行中核对起态/目标并验算；当前仍只是提案，不消费真实启动许可、不推进真实历史。

55项针对性及159项包含针对性的相关测试通过。除同源映射、目标方向、限幅/失败外，还修复了启动q/-q等价误拒绝和运行对象被换成另一构型后未拒绝的问题；两项失败测试和全部历史日志保留。测试通过支持合同实现，不能代替下面的可用性检查。

## 四个失败点揭示了验收定义的缺口

[只读诊断协议](evidence/phase9/fallback-v46-limit-diagnosis-20260920/protocol.json)、[结果](evidence/phase9/fallback-v46-limit-diagnosis-20260920/result.json)。每例仅调用一次原v31静态逆解，再沿同一命令方向应用0.01变化率及原fit命令界，独立重算完整原目标残差。

| 固定请求 | 原逆解达到原目标 | 相对上一命令的最大变化 | 限速后满足原目标残差 |
|---|---|---:|---|
| base，origin64保持 | 是 | 0.020004 | 否 |
| heavy_moderate，origin64保持 | 是 | 0.040505 | 否 |
| uuv6，origin128下调5cm | 是 | 0.074599 | 否 |
| uuv4，origin128下调5cm | 是 | 0.063387 | 否 |

四条限速后命令仍满足原始PWM/死区、fit命令界与变化率。heavy的无变化率逆解还超过原fit命令范围，限制后实际命令留在范围内。这些事实证明四个静态目标可由原源逆解达到，并说明直接限速会留下目标残差；**不证明限制内没有其它耦合轴解，也不证明限速后的闭环稳定**。

base的旧命令为0，有限差分落在PWM死区内，局部Newton无法发现跨分支的力。heavy在origin64已经下沉约0.30m、竖直速度约−0.15m/s，新深度反馈要求约250.13N，而一次0.01变化只能先逐步增加推力。这与旧采集控制高度Kp/Kd为0的事实一致，但本轮不把四例诊断推广为所有失败的完整归因。

因此，“先有静态逆解”与“限速后每一步立即达到完整目标推力”应分开。将它们合成一个硬门会把正常的受限恢复过程也拒绝。现有v46的NO_GO保留；下一版需明确记录限制过程，不能把实际输出重新命名为目标以制造残差通过。

## 下一项具体修正

新增版本采用“完整目标的有界静态逆解 → 明确的命令限制器”：

1. 原深度/姿态需求保持，先验证静态逆解对完整需求的原物理残差、PWM与死区门。优先从已知几何/曲线的解析种子开始，减少对旧命令附近局部差分的依赖；保持10ms预算，不运行无界多分支逆解。
2. 用同一个插值系数限制命令变化，保证实际发令仍位于原fit命令盒内；独立核对实际命令的mask、未裁剪PWM、死区余量和0.01变化率。碰到死区面时只允许有限回退比例，不删死区检查。
3. 分别输出完整目标、静态逆解、实际受限命令及二者对原目标的残差。若静态逆解不合格，仍无命令；若因明确限制而未达到目标，只标记`tracking_limited`，不能称为目标残差通过。目标跟踪是否有效留给后续闭环指标，实际命令合法也不等于系统稳定。

这改变的是后续控制器的受限跟踪语义，必须使用新协议与反例验证，不覆盖v46的验收结果。有限搜索失败、超时、非法源映射或状态越域仍停止该模拟episode。实际一次性启动权限、唯一发令/真实确认、worker隔离及计划过期拒绝仍未实现；完成这些后再提出服务器实验。

本轮新增已测102.713秒，当前本地阶段累计238.289/1200秒、剩余961.711秒；128MiB范围保持。无新依赖、拟合、正式test访问、Isaac采样或晋级，v45与Phase8.4冻结来源/结果保持。复核见[review.json](evidence/phase9/fallback-v46-checks-20260920/review.json)。
