总墙钟最多30分钟，每构型的采集、验收和回读合计最多180秒（含清理预留）；验收只获得该构型的剩余额度，不能另用180秒。源码/模型核验、准备、两个清理探针和8例顺序采集验收均计入总阶段。脚本外层1795秒TERM+5秒KILL是最终停止边界；缺少完整终态记录仍为NO_GO，不可重启当作新额度。

两端研究包（源码、模型、fit资产、日志和结果）合计最多512MiB，每端256MiB；运行端192MiB触发停止以给收尾留余量，轮询间隔50ms。已有共享Isaac/Python安装不计为新增研究包，本轮不安装新依赖。最多一个监督、一个采集/验收、一个求解业务进程，另有至多一个Python资源跟踪辅助进程；单计算线程。SDK自身的线程数不等于这些业务计算进程数。实际文件量和进程清理结果必须复核，轮询监视不宣称操作系统级存储配额保证。

## 结论边界

本轮最多256个控制区间、512个受控物理子步，零拟合、零新训练、不读取正式test，不改变参考。每构型只有约0.533秒模拟时间，只能确认实际接口、切换与该次测得周期；不证明恢复性能、稳定性、持续实时性或控制优势。

下一正式匹配闭环需单独冻结场景、种子、参考变化、时长与资源，并比较Legacy/S-Surface及同优化器/计算预算下的名义物理、辨识物理和当前投影模型。不得把代数等价模型的相同表现解释为独特Koopman收益。
