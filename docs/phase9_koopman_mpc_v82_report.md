# Koopman-MPC：有效性与泛化报告

2026-09-26。本轮10条2秒闭环、18个模型拟合及八折留构型预测已完成；执行范围见 [Goal计划](phase9_goal_v80_plan.md)。本报告回答当前证据，Phase9及长期、未见构型闭环验证仍开放。

## 现在能回答什么

**有局部控制收益，但还没有普遍优势。** 同一有界MPC下，新学习模型在uuv4的2秒任务上比辨识物理模型降低9.8%–11.7%的综合跟踪误差；base则高3.0%–17.9%。两个预先固定的正则候选全部报告，没有事后只保留胜出者。新学习矩阵已实际进入预测器和优化器，与物理模型分离。

控制修正本身也有效：物理MPC＋因果反馈预演，相对反馈控制的综合误差在base/uuv4分别降低34.5%/30.4%；这是整套MPC方案的总收益。单独对比同物理MPC的预演开/关，误差分别降低46.1%/26.0%。更换学习模型所得的额外差异属于当前MPC系统效果，尚不能单独归因于预测精度或Koopman表示能力。

**有一定跨构型预测能力，但没有证明未见构型的控制泛化。** 八折留构型预测总体胜过 persistence，但物理模型总体更准。重型和偏心构型暴露了学习残差的外推问题。

## 物理模型和投影模型怎样区别

“投影”是一种保持姿态、位置等状态合法的计算方式，本身不代表学到了新动力学。旧版投影模型的速度矩阵最终被物理 D/Q 系数覆盖，与辨识物理实际等价，因此不能用旧两条曲线证明独特 Koopman 收益。

新版保留共同的机械信息、输入和执行器模型、位置/姿态运动学；另外用数据学习53个特征到六维速度的读出矩阵，允许出现 D/Q 物理形式无法表达的项。优化器和独立验收器都使用这份新矩阵，已经在真实 CasADi 与 NumPy 中交叉验证。模型应当允许表达不同规律，但不必强求每一步预测不同。

这属于带物理先验与状态投影的 controlled EDMD/Koopman 近似。每一步仍有非线性特征、姿态投影和执行器约束，当前求解是非线性 MPC，不能称为已实现全局精确线性 Koopman 模型或快速线性 QP。

| 控制分支 | 怎样决定指令 | 共同执行端 |
|---|---|---|
| 反馈控制 | 当前姿态/深度误差与速度反馈，加已知物理补偿；当前是 PD，无积分 | 四维 TAM 前指令 → 推力分配/PWM → 死区/转速滞后 → Isaac 刚体 |
| 物理 MPC | 物理模型预测，连续优化未来20个控制区间，仅执行第一条指令 | 同上 |
| 学习 MPC | 新学习矩阵预测，使用相同目标、约束和连续优化器 | 同上 |

目标直接指定为高度5.5m、俯仰增加0.04rad，不来自未来真实轨迹。状态来自仿真器当前观测和因果执行器历史；Koopman 负责预测，不负责视觉感知。反馈预演是在**预测状态**上递推反馈指令，为连续优化提供初值和可行参照，不是固定几个“猜方向”的候选控制器。

## 实际闭环结果

每条运行2秒、60个控制区间、240个物理子步；同初态、seed、权重、约束和20区间预测时域。表中的误差为平均归一化深度与姿态平方误差，越小越好；正收益表示比反馈误差更小。uuv4排除了不可控偏航，因此只在同一构型内比较，不横向比较不同构型的分数。每个单元只有一次开发性短任务，不能据此声称统计显著或长期稳定。匹配物理先验经逐元素和实际预测等价检查后，显式复用v80开启臂，不将复用轨迹多算为新实验。

base 预演开启臂的深度RMSE为0.274mm（反馈2.785mm），姿态RMSE为15.639mrad（反馈18.512mrad）。计入速度、控制强度和末端项后，实际完整目标改善22.5%；控制平方积分增加约8.6%，末端姿态误差也略大，因此不是所有指标都更好。控制平方积分是指令强度指标，不是焦耳能耗。

base的λ=0.001综合跟踪误差比物理 MPC 高3.0%，但完整实际目标低0.86%。它改善了深度和末端姿态指标，也增加了控制平方积分；这属于指标间的取舍，不能宣称整体优于物理。base的λ=0.1综合误差比物理分支高17.9%，完整目标高8.8%。uuv4两个学习候选除跟踪误差外，完整实际目标分别低2.50%和1.09%，但末端姿态误差分别为2.226/2.735mrad，均高于物理分支2.018mrad；不是每项指标都改善，正收益仍仅限本条短任务。

本轮是同步非实时仿真。base物理开启臂稳态完整周期中位数约23.1秒，四个学习臂约9.9–25.1秒，均不满足30Hz；收益来自实际2秒物理轨迹，不能把墙钟求解时间当成物理运动时间。

## 八构型留出预测

每折只用其余七构型的21条激励训练；目标构型的三条历史轨迹仅用于评价。每构型9个窗口，预测80个物理步（约0.667秒），下表为姿态RMSE，单位mrad。输入来自记录的执行器加速度，未来真实状态只用于算误差；这是离线预测，不是闭环。

两候选在80步下均72/72完整；延长到128步时，λ=0.001在重型构型有1/72失败，不能删去失败后宣称全部通过。long_body 的λ=0.1姿态误差有小幅优势，但角速度略差，尚不足以形成整体优势结论。Persistence 只是保持初始状态不变的预测基线，不是 PID 控制器。

## 为什么变差，下一步怎么走

物理基线知道质量、惯量、浮心和执行器，当前静水仿真的动力学形式也与其很接近；同数据辨识得到的修正本就很小。学习模型增加自由度后，容易把训练数据中的相关性误当作可跨构型迁移的规律。

在本轮10条轨迹上，另用三模型对相同实际指令做了600个起点的四子步预测：各模型均完整，学习模型的线速度部分误差略低，角速度误差则更高，不能称整体预测更准。使用原Linux运行时复核，避免把Windows分配差异当作模型误差。[六条物理/反馈分析](evidence/phase9/learned-control-v82-20260926/final-return/analysis-tools/v80-executed-prefix-same-runtime.json)；[四条学习分析](evidence/phase9/learned-control-v82-20260926/final-return/analysis-tools/v82-executed-prefix-same-runtime.json)。同运行时由各自`.receipt.json`绑定实际解释器、源码和结果SHA；原分析JSON的保守平台标志不单独构成确认。这项诊断不模拟替代控制器的反事实闭环。

**求解质量是另一个独立问题。** base三个控制器的首次求解起点、启动命令和执行器历史完全相同。在原Linux运行环境交换三条真实选中计划做3×3精确评价，九格都可行，三模型都把物理分支计划排为最好。按各学习模型自己的目标，换用这条已知可行计划即可将首个预测成本再降低约1.8%（λ=0.001）和19.4%（λ=0.1）。三次首次求解均达到160次迭代上限、未报告收敛。这证明当前有界非凸求解遗漏了自己认可的更优解；它只诊断首个起点，不证明全部闭环差异由求解造成，也不是新的反事实闭环收益。[同环境交叉计划证据](evidence/phase9/learned-control-v82-20260926/base-return/analysis-tools/base-initial-plans-same-runtime.json)。

离线干预给出了更具体的证据：重型构型的线速度二次阻力特征向角速度产生过大的交叉修正，移除这组**学习增量**后姿态误差下降92.5%；偏心构型的恢复力矩x/y学习残差外推失准，移除后下降83.4%，接近物理模型。全部12组消融和252次预测保留；这是事后根因诊断，没有据此挑选并部署新模型。[根因证据](evidence/phase9/learned-velocity-v81-20260926/loco-root-cause/README.md)。

uuv4的首次起点也完全一致，九格交叉计划均可行，三模型都把λ=0.001分支的计划排为最好；其首次求解119次迭代达到acceptable，物理与λ=0.1均到160次上限。这反过来说明物理分支也遗漏了自己认可的更好解。两构型的证据一起指向有界非凸求解质量这一混杂因素；局部控制收益真实存在，但尚不能全部归于模型更准。[uuv4交叉计划](evidence/phase9/learned-control-v82-20260926/final-return/analysis-tools/uuv4-initial-plans-same-runtime.json)。

下一步按以下顺序推进：

1. **先修求解与复现。** 用两构型已知可行优解做离线回归，核对共同因果初值、迭代上限与收敛残差；定位预演跨平台首次分支差异，保持原因果门，不用更大容差掩盖。暂不优先压实时周期。
2. **再检查学习残差是否必要。** 保留可信物理项、约束缺少数据支撑的交叉残差，按诊断补激励覆盖；同数据物理基线继续保留，不人为削弱对手。
3. **用新任务验证。** 另冻结初态、目标和扰动，先重复2秒对照，再延长；真正未见构型闭环必须排除该构型拟合和支持域泄漏。在线自适应、Agent贡献和实时化仍后置。

本轮报告Goal到此收口；不把局部成功当作Phase9完成，也不继续筛模型直到胜出。全部旧失败、首次预检失败及资源费用保留。
