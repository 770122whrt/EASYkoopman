# Phase8.4 fresh pilot：已超过 persistence 的范围，以及跨构型失败的具体原因

2026-09-12。本轮21个固定模型全部拟合完成，主试验结论是 **NO_GO**：留出整个构型时，uuv6仍有长递推越界，不能进入正式D-23或Phase9。但把三个构型都纳入训练后，模型在全新验证episode上的表现明显优于persistence。这两件事需要同时保留。

三构型联合训练的非线性模型在128步固定起点验证中9/9存活；其20/60步相对persistence的带工程下限归一化宏误差为0.0388/0.0494。同信息线性模型为0.3871/0.5490。这里的非线性提升有明显诊断收益。因果物理输入也比4D命令+EMA代理更可靠，后者出现大量长递推失败；失败的对照不能用于计算“完整比较胜出”。这些是有界pilot结果，不能当作正式模型晋级。

更准确的理解是：**已经训练过该构型的模型，能预测该构型的新episode；没有训练过uuv6的模型仍失败。** 不是“混合多个构型训练一定更差”：本轮联合训练反而比各构型单独训练更好。

留构型结果也不均匀：留出base时20步线速度/角速度RMSE为0.008712/0.109712；留出uuv4为0.003052/0.002378；留出uuv6增至4.994717/3.038233。uuv6的PRBS128步递推在第128个物理步，即第64个控制区间越界；60步滑动评估有31个起点失败，完整宏平均置空，没有只统计幸存者。

## 2. 为什么 uuv6 跨构型会差这么多

已确认的一条机制是**输入通道不可辨识后，算子在新构型输入上产生巨大错误响应**：

1. 仅用base/uuv4训练时，水平加速度输入Fx/m的标准差只有2.65×10⁻⁶，最大绝对值7.04×10⁻⁶ m/s²；它与Fz/m的相关系数为−0.999999956，近乎同一方向。
2. 模型自由学习整个输入矩阵，拟合得到了Fx/m→下一步垂直速度的系数 **−1125.906秒**。同一瞬间、相同体坐标系下的刚体直接受力关系不应有这样的交叉增益。标准化后的ridge条件数约14031，仍通过原数值门；数值可解不代表物理关系可辨识。
3. uuv6验证中的Fx/m达到0.004314 m/s²，是训练标准化尺度的约1627倍。只看这一个错误项，单个物理步就可产生 **4.8567 m/s** 的虚假垂直速度贡献。还存在yaw力矩输入范围约9.85倍的外推。

这个系数分解直接证明当前模型怎样产生错误输入响应。它不等于已经完成整个长递推误差的百分比归因，也不说明所有跨构型任务必然失败。训练时缺少独立输入方向，与新构型的TAM/PWM非线性产生的实际受力范围变化，共同暴露了自由输入矩阵的问题。

初始化、动作时间和执行器状态问题已分别修复/验证，但修复采集链并不会自动赋予模型未被数据辨识的物理结构。GPU算力或简单加大网络不能保证消除此类错误系数。

## 3. persistence 是什么，为什么它曾经更强

此处persistence直接令未来状态等于当前状态：`预测x(t+h)=x(t)`，不训练参数、不使用未来动作。很短时间内，UUV状态变化有限，所以它是很强的最低基线。原模型的输入语义缺漏、错误初始化、不可辨识系数及递推误差会让预测偏离真值，反而输给“保持不变”。

本轮已经证明，在已覆盖构型的新episode上，因果执行器物理输入、非线性字典和已知姿态运动学组成的预测器可以明显超过它。尚未证明的是：在没有目标构型训练数据时仍具有同样的可靠性。

## 4. 这能证明 Koopman-UUV 吗

可以支持继续研究**受物理结构约束的Koopman提升预测**，但不能声称已经证明端到端线性Koopman-MPC。模型拟合了完整提升观测量算子，实际预测每步使用已知运动学更新姿态并重新提升，完整预测器属于非线性混合结构。

保持同一个非线性算子、取消重新提升的对照明显变差。例如联合训练60步线速度/角速度误差从0.005527/0.015638增至0.100884/0.151963。这说明收益包含投影/运动学的贡献，不能全部归功于有限维线性提升的封闭性。Agentic贡献和闭环控制还没有验证。

## 5. 下一步

保留本轮NO_GO和全部21个模型。先检查并约束已知的刚体受力关系，避免从近乎没有激励的数据重新学习全输入矩阵；Koopman部分负责剩余状态演化，并设置同结构线性/无学习物理对照。必须先确认有限时间步、体坐标旋转和力矩积分语义，不能直接把连续时间公式当作精确仿真离散方程。

后续作为新的结构假设试验，使用新协议和新验证种子；本轮数据可用于诊断，不能再充当未见验证集。若需要目标构型少量校准数据，应明确改称适配，不能保留零样本迁移的表述。Phase9、环境适配和Agent Supervisor继续依赖合格模型/控制合同。
