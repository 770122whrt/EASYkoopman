## 1. “同一策略”的可执行定义

采用 `u_k = pi_theta(x_k, reference_k, causal_actuator_history_k, configuration)`。跨构型保持同一控制实现、同一组学习参数 theta、同一目标权重/归一化规则、预测时域、优化算法/初始化规则、截止时间、回退规则和安全约束生成规则。若后续接 PPO，其网络权重和动作解释也须冻结。

构型的质量/惯量、推进器布局与数量、TAM、可控轴 mask，以及依同一规则计算的启动配平和机械约束可作为输入变化。由共享映射生成构型相关预测器是条件化策略；为每个构型手调代价、单独训练控制器或按测试结果挑模型，不能计为同一冻结策略。安全条件不能为了相同数字而忽略实际机械差异，任何差异都须有统一生成规则和事前信息来源。

不要求不同构型发出相同命令。所有构型都评价共同可控的深度/倾斜目标；有偏航控制能力的构型另报偏航结果，`uuv4*` 不承担不可实现的偏航目标。整体平均之外保留逐构型失败、约束违反与回退情况。

## 3. 分三层评价泛化，先做当前能够承接的一层

1. **已知构型上的统一控制。** v58 实际接口/时序通过后，以同一 pooled 模型、同一控制设置，在八构型上运行事前固定的新初态和参考。先用外部统一参考比较下层 Koopman-MPC 与 Legacy/S-Surface，不同时重训练 PPO。报告为已知构型的新任务/轨迹泛化和跨构型统一控制能力；训练见过八构型并不使这项实验失去价值，但不构成未见构型证据。支持域不足时报告拒绝，不看过失败轨迹后扩大范围。
2. **未见构型上的冻结迁移。** 每折只用源构型训练/选模型/定权重，同一冻结策略运行在源构型与留出构型上。整个 LOCO 评估可以有八个源训练折，不把八折模型伪称为一个模型；每一折目标构型运行前不得微调。质量/布局等已知机械描述符的来源须列明，结论限定为给定这些信息的迁移。
3. **未见工况和组合变化。** 冻结零更新结果先报，再以相同工况测受限在线更新。训练范围内的新组合和训练范围外的变化分开，不能把更新后的结果算入零更新泛化。

第 2 层的前置缺口是独立的目标构型运行范围：需要基于源数据、已知机械界和预先规定的转换规则提出并验证新的准入接口，同时保留原硬安全门。若必须采集目标构型标定轨迹，这些样本及用途必须计入目标访问预算，结论改为标定辅助/少样本适应，不能宣称目标零数据。既不能复用目标 fit 盒假装无泄漏，也不能把 diagnostic 大盒当作已验收运行范围。

训练源、状态估计信息、构型描述符、支持域来源、调参数据、在线更新开关和 PPO 是否冻结是每个比较组必须写清的字段。实际未知的环境/故障参数不能从仿真真值直接交给被测控制器；真值信息比较组单独标注。

## 4. 自适应和跨任务经验积累的后续边界

Phase 10 先固定更新对象及可辨识性，再建立候选更新、独立检查、版本切换和回滚；一次 MPC 求解使用固定模型快照，新模型切换须处理旧请求/计划失效，不能解除原 context/history 绑定来强行运行。预测在新观测到来前生成并保存；新观测到来后先计算并记录误差，之后才允许使用该观测更新。

冻结模型与在线模型比较变化后的累计跟踪误差、恢复时间、样本量、约束违反和回退。只更新 D/Q 时报告物理参数适应；更新已准入提升模型系数时说明具体矩阵/块，而不是泛称完整算子学习。

“自进化”采用可检验的跨任务定义：保留已验证的模型/经验，在 `A -> B -> C -> A -> B` 及未见组合 D 上考察再次遇到工况时的样本效率与旧任务保留。与每任务重置更新、连续更新但无模型库比较，匹配数据访问、计算和存储预算；重复访问使用新轨迹/噪声，不能记忆测试序列。控制器和执行器每次按同一真实 reset 初始化，仅允许声明的学习记忆跨任务保留。模型晋级用开发资料，最终评估数据不反馈为筛选依据。

先建立规则化更新/记忆机制，再由 Phase 11 比较无监督器、规则与 Agent 的同权限决策；Agent 只选已准入的模型/更新方案，不发 PWM、不修改冻结测试权重或放宽约束。Phase 12 同时报告跨构型、适应效率、遗忘以及成本。这里不预设收益必为正，也不预先扩展到自动改代码或硬件 Sim2Real。
