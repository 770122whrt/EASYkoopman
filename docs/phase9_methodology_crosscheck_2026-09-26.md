# 控制、模型、验证三端交叉审核

2026-09-26。依据用户提供的两份论文原文、当前控制代码、v78真实记录、v79本地诊断及独立代码审核。页码均为PDF页码。**主线合理，当前证据尚不足以证明独特Koopman收益；新增闭环须先补验收缺口。**

## 1. 两篇论文该借鉴什么

| 原文依据 | 可借鉴的思想 | 本项目判断 |
|---|---|---|
| [Koopman论文](../../Research/agentic-auv/Sources/Papers/Koopman-based.pdf)，p3式(3)–(4) | 优化整段连续控制序列，只执行第一步，下一时刻重新求解 | 当前连续MPC符合；Koopman预测状态，优化器计算控制，不是枚举几个方向 |
| 同上，p4 IV-A、p5 Fig.3–4、p7 V-B | 同数据拟合物理与学习模型，同MPC和参数比较；预测和控制分别评测 | 现有名义物理与投影分支只能区分D/Q参数；必须加同数据辨识物理，以及真正非等价的学习动力学 |
| 同上，p5–6 IV-B | 新参考信号、PID/SMC产生的轨迹、不同预测时域检验泛化；报告重复试验 | 当前单初态、固定0.04rad目标、2秒开发任务不具备同等证据；论文是同一机器人跨信号/控制器，不是跨机器人构型证明 |
| 同上，p6–7、Table II | 冻结模型、RLS、KF及参数模型的消融，将在线更新和提升表示分开 | 后续自适应应先预测再看到新观测、再更新；先做无Agent对照，不能用修改模型后再预测同一个样本的误差证明进步 |
| [EasyUUV论文](../../Research/agentic-auv/Sources/Papers/EasyUUV-TIE.pdf)，p3 Fig.2、p4式(3)–(4) | RL给偏差指令，下层A-S-Surface转低层控制，LLM调整参数 | 当前实验固定外部目标、用MPC替换下层，RL/LLM未参与；这是下层模块实验，不是完整EasyUUV复现 |
| 同上，p5–7 Fig.5–10/Table II | 有/无RL、不同下层控制器、域随机化及浮力扰动分别比较 | PD+物理补偿是当前明确基线，不能称原论文PID或A-S-Surface。完整系统结论还需适配原控制器及RL开关对照 |
| 同上，p9限制段 | 原文明确限于单一UUV与姿态跟踪，LLM调参无严格稳定保证 | 多构型是值得验证的扩展，不是已被原论文保证；先固定控制器，再研究适应和Agent增量 |

论文也需要批判性使用：Koopman论文p3式(8)将目标误差作为提升量，p4明确学习模型额外使用参考信号，而物理基线只用初态与控制。已知目标不是未来状态泄漏，但信息不对称可能混入收益。本项目主模型对照应先共享状态、输入、机械信息和执行器历史，目标仅进入共同MPC目标函数；如果引入参考条件模型，须单列同信息消融。

其p4的KF公式也有实现歧义：观测式(10)/残差(9d)使用f[k]，增益(9c)/协方差(9f)却写f[k+1]，正文Q的适应没有完整显示在协方差预测(9b)中。已核对页面图像，不能直接照抄；未来实现应依据一致的因果回归式重新推导并验证，不据此断言论文代码必然错误。

EasyUUV论文p4推进器拟合的死区是±0.08；本仓库冻结plant代码的PWM转速死区为±0.02。二者不是同一执行模型，禁止仅为“对齐论文”改动plant或把论文参数直接塞入当前控制器。保持实测执行映射、明确差异即可。

## 2. 三端目前是否正确

| 端 | 已成立 | 需要修正或补证 |
|---|---|---|
| 控制 | 4D pre-TAM连续序列 → 构型mask/分配 → PWM → 有记忆的转子 → plant；状态与过去执行回执反馈，预测不推进实际历史 | 预演需同一新版入口开/关配对。预测代价降低不保证实际误差降低；非凸求解超时或未找到解不等于证明不可行 |
| 模型 | 名义物理、辨识物理、结构化投影身份已显式区分；12起点80步辨识/投影差≤5.55e-17 | 当前有效读出只体现D/Q，不能把两者当不同表示。保留可靠解析运动学，另开发影响速度动力学的学习提升读出；不能改名或直接恢复已经失败的完整矩阵 |
| 验证 | 旧2秒原始状态/命令/执行器历史与评分可复算；负收益保留 | 新记录尚未接完整Isaac验收；实际PWM门遗漏；短计划可因广播逃过选择审核；仅核对日志已有清单无法发现遗漏 |

本轮修复短计划/非有限值验收，增加明确preview开关和初始化/worker/参考记录；新增单决策独立审核，从输入重建held、从已确认前序计划重建warm，并对ready preview重新做因果预演。它仍不是整个Isaac轨迹验收器，不能认证调用者提供的历史回执，也不能凭日志证明worker搜索的全局最优。

**当前收益应这样读：** v78的uuv4短开发任务中，投影分数相对PD补偿反馈改善约12.15%，名义物理MPC改善约10.61%；另外三构型统一配置未改善。uuv4曾用于选权重/时域，属于开发正例。旧uuv6两臂实际PWM各16子步不满足补充的直接余量门；原数字可复算，不能升级为新门全部通过。没有新学习模型收益、跨未见构型收益或Agent收益证明。

## 3. 修正后的实验顺序和判定

1. **当前服务器诊断：** 冻结模型/支持域/目标/H20/深度权重4，base和uuv4各取反馈记录的第4物理步，同起点preview关闭/开启，共最多4次真实CasADi调用。另对8条旧MPC轨迹比较服务器CPU、GPU分配与原始PWM。零训练、零新物理；总诊断外部硬限600秒、单worker原30秒CPU/45秒墙钟不变；新增包和证据两端各128MiB以内（含隔离源码快照与传输包）。异常停止余下求解，保留已花费和失败。只验证求解接口/因果审核/平台边界，不计算新闭环收益。
2. **2秒控制修正对照：** 补齐新版采集和完整轨迹验收，直接检查每个实际PWM；根据平台误差给求解端留数值内缩余量，实际2e-6门不变。在同一新版代码上开/关preview，共享模型、求解预算、余量门和初态。先base负例与uuv4正例，后long_body/uuv6。旧v78不能直接充当关闭臂，因为新验收/内缩也变了。报告深度/姿态RMSE、末端误差、控制强度、失败和回退、求解耗时；不只报综合分数。
3. **模型收益对照：** 单列训练设计，使用原fit数据拟合超出D/Q表达的学习动力学，保持运动学和执行链；先在独立数据比较同输入1步与覆盖MPC时域的自由递推，再以同MPC对比名义物理、同数据辨识物理、非等价学习模型，另设反馈。无需为证明模型身份强行学习已知姿态运动学。当前历史开发/正式test不回流训练；低速窄域数据不能自动支持强激励控制。
4. **泛化与自适应：** 冻结统一控制配置，使用未用于调参的新初态/正负目标和较长任务，随后第二组构型。见过各构型数据的pooled模型叫已知构型覆盖；真正跨构型泛化需留出构型，允许同规则机械描述输入，不按目标构型重训。确定性仿真仅换seed而轨迹没变，不算独立重复。在线适应/Agent在基础模型控制成立后另做更新开关、RLS/KF、无Agent/规则Agent对照。

2秒适合检查方向、瞬态、执行链和早期约束，通常不足以量化稳态、完整低频正弦跟踪或抗扰恢复。阶段通过表示能继续验证，不表示收益已证实。两篇论文的百分比、任务尺度和评分都不能直接成为本项目成绩。

### 本轮服务器实测

使用suanliyun-agentic-AUV现有隔离依赖：Python 3.11.13、NumPy 1.26.4、Torch 2.7.0+cu128、CasADi 3.7.2、RTX 4090。原641项源码逐项哈希一致后增加v79接口，独立快照未覆盖历史实验。首次打包漏带测试模块，第二次缺归档物理循环夹具；补回原哈希文件后复测，两次失败记录保留。**本地109项、服务器109项均通过，无跳过。**

四次最终计划均通过精确可行性、全部参考重算、因果预演重算及单决策记录审核。uuv4保持参照不可行，两次MPC都找到了精确可行计划。两次开启preview的IPOPT都达到160次迭代上限，返回的可行点被接受；不能称四次全部收敛，更不能称全局最优。开启预演这两例更慢，速度仍未解决。原控制门、模型、目标、时域均未放宽。

PWM复核覆盖8条旧MPC轨迹的1920个实际子步及480个控制区间起点。**服务器GPU重算raw PWM与记录差为0**；CPU/GPU最大差：base/long_body为0，uuv4约2.98e-8，uuv6最高3.73e-8。因此已将这些记录中的平台差异定位到CPU/GPU分配计算，而非Windows回传精度。uuv6两臂各16个实际子步仍被原2e-6直接余量门拒绝；无删样本或调阈值。这不是全支持域浮点误差上界，也不证明负控制收益由这项差异造成。

原生诊断进程103.36秒；含三次测试进程和编排/回传前校验累计约135.03秒，低于600秒。新增物理步/拟合均为0，所有worker和进程组正常退出，源文件校验无变化。证据已回传，关键原始记录/退出记录/JUnit/源码复核记录哈希一致。无遗留任务，服务器无需为后台任务保持开启。
