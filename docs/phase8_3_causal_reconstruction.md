# Koopman输入与执行器状态的因果重建检查

2026-09-12。研究主线按用户确认保持Koopman-UUV／Agentic-AUV，由学长建议与代码/实验判断共同推进。普通线性、分构型模型和persistence继续用于诊断与公平对照。此次补充检查支持继续研究完整子步输入与可计算执行器状态，尚未检验Koopman预测收益。

仅使用已通过初始化验收的四条cold观察轨迹，32control intervals/条，共128区间、256子步；没有新增Isaac运行或模型拟合。warm与trace-off重复轨迹不计为新样本。每条轨迹仅给重建器预先确定的PRBS动作、零初始控制历史、零初始执行器状态、已知控制器/分配/执行器参数，按原顺序计算两次控制。测量PWM、转速、wrench和未来艇体状态只用于计算误差，不反馈给重建器。

阈值在运行前固定为：virtual control/PWM绝对误差1e-6、速度命令/转速估计绝对误差1e-3，未按结果调整。

全部通过预声明门。速度命令最大误差6.1035e-5，转速估计使用执行器内部转速单位（沿用rad/s约定，未增加实物标定）。同一控制输入历史经CPU核/独立递推与真实GPU记录存在微小数值差异；不将它们宣称为逐位一致。

这项检查确定的是：在当前**预设raw-action、已知执行器参数、已知零初值**的控制路径下，两个子步的控制与执行器状态可由当前区间已有信息生成。因此后续Koopman输入不必依赖区间结束才知道的实测控制；执行器状态也可以从命令因果递推。控制历史的保留和N维槽位对应的推进器几何仍要明确。

这里还没有证明N维状态优于4D proxy，也没有比较末值输入与有序输入对预测误差的收益；没有验证未知转速初值的状态观测器，更不能外推到依赖未来艇体状态的反馈内环。不得把转速重建正确等同于艇体动力学预测正确。

样本只有四条不同观察轨迹、三构型、一个激励家族；每条0.533秒，动作只有5或7种不同向量。后续先完成输入/状态对照和覆盖审查，随后制定整段fit/validation隔离、包含不同激励的fresh pilot。32步数据不用于宣称60/512步或跨构型泛化效果。

研究论证分层推进：先验证Koopman模型/控制链的一致性和作用，再通过无Agent、规则Supervisor与Agentic方案的匹配对照检验上层增益。固定反馈或普通线性基线的收益分别标注，模型身份与实际贡献保持一致。
