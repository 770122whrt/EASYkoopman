# Phase 9：首次真实闭环局部收益与剩余瓶颈

2026-09-21。结论：**已观察到 base 俯仰任务的短时跟踪收益；尚未证明普遍收益、跨构型收益或 Koopman 独特表示收益。** 本轮有界pilot已结束，Phase 9没有收口，MPC2要求不能因此全部勾选。

## 1. 实际结果与适用范围

在真实Isaac/EasyUUV中，两臂均从z=5.5m、直立、零转速启动，目标pitch=0.04rad、深度保持5.5m；同一seed、120个控制区间/240物理子步/2秒。对照是受约束反馈；实验组是冻结nonlinear__pooled投影模型＋编译MPC。不是persistence控制对照。原TAM、执行器记忆、物理参数、约束、H20、8步承诺前缀不变，零拟合/训练。

| v65 base俯仰任务 | 反馈 | Koopman-MPC | 变化 |
|---|---:|---:|---:|
| 事前综合跟踪分数，越小越好 | 0.2362194 | 0.1927060 | 降低18.42% |
| 俯仰/可控姿态RMSE | 0.0186511rad | 0.0175512rad | 降低5.90% |
| 深度RMSE | 2.7427mm | 0.2668mm | 降低90.27% |
| 命令变化总量 | 0.0886506 | 0.2376384 | 2.68倍 |
| 实际力平方积分 | 0.2633862 N²s | 0.1827461 N²s | 降低30.62% |
| 实际力矩平方积分 | 0.0164620 (Nm)²s | 0.0942545 (Nm)²s | 5.73倍 |

MPC实际激活14次，120区间的命令来源为14个mpc、105个committed_prefix、1个fallback；承诺前缀也包括早期反馈承诺，不能把105个全部算作新优化决策。两组命令最大差0.0546183。两臂全部物理/命令历史重放通过，并在本地再次独立重放和重算指标；满足事前≥5%综合改善及独立误差绝对改善门。不能忽略力矩与命令平滑性代价。

这是单构型、单seed、2秒、零扰动的小阶跃描述性证据，没有统计显著性或长期稳定性资格。当前冻结模型与同D/Q参数物理模型代数等价；这组结果证明完整预测控制方案相对该反馈对照的局部收益，不能把收益单独归给Koopman表示，也没有与Legacy/S-Surface或同优化器名义模型完成比较。原v38只提供限定预测证据。

## 2. 失败、修复与计时

| 版本/病例 | 已完成控制区间 | 结果 |
|---|---:|---|
| v65 startup-base | 2/32 | 首周期28.965ms按启动计；第二周期29.094ms仍超16.667ms |
| v65 base-depth反馈 | 88/120 | static_inverse_not_found |
| v65 base-depth MPC | 101/120 | 同一静态逆求解失败；11次MPC激活，不据较长运行宣称收益 |
| v65 base-pitch反馈/MPC | 120/120、120/120 | 完整匹配局部收益，如上 |
| v66初次包装 | 0/120 | collector误读R2清单，被来源检查拒绝；失败保留，r4仅修清单路径 |
| v66 base-depth反馈/MPC | 118/120、120/120 | 反馈10.178ms超10ms门；MPC完成但无完整配对 |
| v66 base-pitch反馈/MPC | 71/120、120/120 | 反馈323.656ms超10ms门；MPC完成但无完整配对 |

静态问题来自“必须先得到达到原残差门的静态目标，才允许动态跟踪发令”。真实失败目标约0.571/0.719N，纯heave静态扫描显示死区及约1.33N附近的非零推力跳变；把逆求解迭代上限4增至8仍未找到解。此扫描不是全4D不可解证明，也不是全局最优证明。

v66实现新的有界近似策略：仅在原static_inverse_not_found且候选有限合法时使用有界搜索找到的候选；重检约束，并与合法hold按原归一化残差分数比较。原目标和残差阈值不改，未满足仍标tracking_limited/static_residual_unmet。两臂反馈及MPC恢复基准同改，启动精确权限、实际前缀、支持域、slew、死区距离、截止时间不变。保留原v65版本。深度反馈实际越过旧失败点，已完成前缀中30次近似跟踪经离线重算确认；这只是局部修复证据，尚不是整条运行修复完成。

修订后反馈决策中位数约1.09–1.16ms，p95约1.84–2.97ms，但出现10.178ms和323.656ms尾延迟。后者并未因“startup例外”被豁免，均停止发令。没有足够剖析证据区分逆求解/原生库停顿/服务器调度，不把它直接归因于GPU不足或v66新增计算。两条MPC完成时仍各14次激活；不能拿未完成反馈轨迹的前缀与完整MPC比较后宣称收益。

原版匹配俯仰两组稳态周期p50约26.16/25.13ms，所有119个稳态周期都超过16.667ms；单纯首周期豁免不能解决。效果协议保留120Hz物理步长、60Hz控制及原worker100ms/决策与回执16.667ms门，物理边界外等待结果后才在下一边界交付；准入年龄按实际已确认物理时钟。墙钟超时单列，因此本轮不证明实时部署，不能称60Hz合格。

因v66 base匹配完成门未过，原定asymmetric/uuv4八条未启动；无跨构型结论。停止而非继续扩大范围或放宽门。

## 3. 下一步及证据入口

继续Koopman-UUV方向有依据，但只够支持进一步验证：

1. 先定位反馈尾延迟。对上述两个实际失败状态做有界、固定输入重放，分别量逆解、分配/原生库与调度耗时；必要时记录线程/CPU亲和性后对照。优化须保留实际命令与约束等价；不直接放宽10ms/16.667ms门，也不默认GPU能解决。
2. 然后同版本重跑完整base深度/俯仰配对，补重复运行和更长参考跟踪；明确保留首次失败率及启动成本。通过base门后才扩到asymmetric、uuv4，再到八构型。固定策略、相同机械信息权限，不按构型手调。
3. 分离收益归因：反馈/Legacy对照回答控制收益；同MPC下名义参数模型 vs 辨识参数模型回答参数收益；同MPC、数据/信息/预算匹配的线性或非线性物理模型 vs 合格Koopman模型回答表示收益。当前同D/Q等价分支应报等价，不能人为制造Koopman增益。在线适应与Agent留在这些基础证据之后。

两篇论文只借鉴思想：[Koopman-based，第3–7页](../../Research/agentic-auv/Sources/Papers/Koopman-based.pdf)中的学习预测模型接MPC、模型/更新分开对照；[EasyUUV-TIE，第3–7页](../../Research/agentic-auv/Sources/Papers/EasyUUV-TIE.pdf)中的物理/TAM/执行链与分层控制保留。未移植论文代码；参考输入权限不对称的对照不用于独特优势归因。

本轮10/18次启动，服务器采集＋分析500.423/1800秒；各组已退出，GPU无本任务进程，服务器可关闭。原v59的684个冻结源、原环境2965文件和Isaac既有patch核验未变。新远端2.85MB、远端累计研究包173.15MB、环境322.63MB，处于原上限。本地只回传本轮31份明确结果/轨迹/清单并逐文件哈希核对；整目录回传被自动审批拒绝后未继续尝试。最终130项关联测试通过；此前加强独立审计的22项针对性检查也通过。完整重放4例通过，失败不改写为成功。
