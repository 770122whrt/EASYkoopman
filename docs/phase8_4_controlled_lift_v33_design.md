# v33：受控提升输入时序的限定修复对照

2026-09-13。承接07计划和r19独立验证。用户已授权顺序验证/修复及日常实现选择；本轮只做本地source/fit-only对照，无新服务器采集，不修改34个冻结模型或r19原评分。

## 方法判断

重新投影是有限维Koopman近似中可以明确采用的方法；其动机是有限近似未必保持真实观测量流形不变。因此“需要投影就不是Koopman”不成立。当前未证明的是完整算子贡献及控制接口可用性。[van Goor等原始论文](https://arxiv.org/html/2307.16188v1)。

对于有输入系统，离散时间提升后的输入作用通常依赖状态，甚至同时依赖输入；直接假定常数B不普遍成立。[Iacob、Tóth、Schoukens原始论文](https://arxiv.org/abs/2207.12132)。经典线性提升MPC的简便优化依赖其实际使用的`z_next=A z+B u`形式，不能直接转移到有非线性输入映射和每步投影的实现。[Korda、Mezić原文](https://mgroup.me.ucsb.edu/sites/default/files/publications/koopmanmpc.pdf)。

| 选择 | 能回答什么 | 当前取舍 |
|---|---|---|
| 保持v30投影 | 已知物理结构和有限参数辨识下的可用预测 | 保留强比较器；不能单独显示完整提升算子收益 |
| 修正完整离散提升的输入时序 | 原发散是否主要来自控制作用与位姿更新不一致 | 本轮唯一修复；字典、D/Q和ridge不变 |
| 结构化生成元/双线性近似 | 以显式受控形式组织可学习动力学 | 暂不实现；需单独处理连续导数/离散求解器、输入交叉项和辨识性，不能把一次Euler离散当精确流映射。生成元方法参见[Klus等](https://arxiv.org/abs/1909.10638)。 |

## 明确的离散合同

状态`x=[z,q_wxyz,v_body,omega_body]`，参数`c`来自当前构型实际机械/流体上下文；步长1/120秒。输入`a`是由已发命令和过去执行器历史得到的作用加速度，不能由未来真值获得。

记`F_theta(x,a;c)`为已冻结v30物理参数D/Q对应的预测速度、位姿更新及body/world转换。固定观察量`psi_c(x)`仍是v30非线性53维字典。本轮将旧的同姿态瞬时kick替换为

`Delta_33(x,a;c) = psi_c(F_theta(x,a;c)) - psi_c(F_theta(x,0;c))`。

由此零输入作用严格为零，同一步的高度/姿态/二次观测量均包含控制作用。拟合目标是`psi(x_next)-Delta_33(x,a)`，**不使用未来真值来计算Delta**。同一训练范围的原D/Q、角阻尼和六个速度列保持不变；只对其余提升输出用原固定mean-ridge 1e-6重拟合一次。其余参数、样本权重、中心化与缩放均沿用v30。

实际完整递推为`z_next = z A + Delta_33(decode(z),a)`；decode将R读回最近旋转，仅用于状态读出和下步输入映射，**不将z替换为psi(decode(z))**。完整提升输出参与随后递推。零输入是无外推进器加速度，不等于冻结控制、静态配平或无重力/浮力。

这仍是状态/输入相关的受控有限近似，非全局精确闭合、非常数A/B。Delta需要调用物理参数预测两次，故即使它通过也不能凭此声称比物理模型快，或证明独立学习收益。该依赖是明确成本，不藏进“已知输入”标签。该对照首先用于查错和否决不充分路线。

## 执行前冻结的范围

只读已验收24fit。继承非线性pooled与8个heldout的9个冻结D/Q模型，各一次拟合，无字典/超参数/种子扫描。比较同一scope的：旧A+旧输入；旧A+修正输入（不重新拟合的机制干预，不是有效新拟合模型）；新A+修正输入。另报告原投影非线性、匹配线性、已知物理和persistence。local不新增拟合。

全部合法激励段起点，1/20/60/128控制区间；每episode另报起点0的320区间全段预测。每条报告完整/失败起点、首个失败步、终点/path四组误差；任何起点失败则本条误差为null，不给幸存者均值。数值界沿用v32：abs(z)≤100，六速度分量绝对值≤100，四元数norm误差≤.001。完整提升额外报告离开观测量流形的距离，仅作机制描述，不把事后阈值用于选模。

共9个新完整矩阵；24episode×12条预测路径×4时域=1152条激励段评分，另288条全段评分，共1440条。12路径为两scope×三个完整算子条件、两scope×原非线性投影、两scope×原线性投影、已知物理及persistence。

这批fit上的heldout诊断保持每模型训练排除，但整个fit已被研究者观察，不宣称独立validation或未见平台。结果输出新目录，原模型/fit设计/validation冻结文件不可修改。
