# Phase 8.4：随姿态补偿与有界反馈校准 v28

2026-09-13。用户已明确同意修复 asymmetric 并按前一份结果文档的下一步执行。本协议在新物理运行之前确定。历史 v27/r11 记录保持原样。

目的：检验固定初态配平的失稳是否能通过随姿态更新的恢复力矩补偿和有界反馈修复，并检查八种构型能否采用同一种采集控制规则。此处使用已知物理参数，尚不检验 Koopman 或 Agentic 收益。

## 修复及控制边界

- 保留质量、惯量、浮心偏置、体积、推进器曲线和一阶滞后。零速度、单位姿态、零转子转速从 5.5 m 开始，完整记录启动过程。
- 控制间隔仍为 1/60 s，每个间隔两个 1/120 s 物理子步。每个间隔读取当前边界状态，保持一次四维 pre-TAM 指令；原有 plant 子步更新不变。
- 以当前姿态计算 `r_COB × (B Rᵀ e_z)` 并施加相反力矩。单位姿态为参考，姿态误差采用最短四元数的 `2 q_vector`。
- 共用姿态增益 Kp=9 s⁻²、角速度 Kd=6 s⁻¹，按各构型惯量换算力矩；每轴反馈加速度限幅 ±16 rad/s²。该参数选择对应小角度理想模型的 3 rad/s 自然频率与临界阻尼，不保证含滞后和欠驱动的真实系统稳定。
- 高度 Kp=1 s⁻²，竖直速度 Kd=2 s⁻¹，反馈限幅 ±1 m/s²；使用实际体重与浮力差。只分配可控的体坐标升沉力，未分配横向力单独记录，不声称六自由度悬停。
- 所有构型使用同一规则，按实际质量、惯量、浮心和控制掩码参数化。uuv4 不产生不可控偏航输入。实际指令仍经过源代码中的分配和 PWM 曲线。
- 每个决策记录输入状态、补偿项、反馈项、物理脉冲、目标力矩/力、未分配项、求逆残差和最终指令。控制器不读取未来状态或转子真值。
- 使用 v27 的已知稳态映射求逆；实际转子仍从零开始累积。求逆不等于消除滞后。原残差门限 `[.025,.025,.025,.1,.1,.1]` 和至少 5% 原始 PWM 余量不放宽；分配不满足则在发送前停止。
- 新 collector 清理后仍传播原始失败，禁止 SimulationApp 的 `SystemExit(0)` 掩盖采集失败。

## 固定范围

八种构型：base、long_body、heavy_moderate、asymmetric、uuv6、uuv6_angled、uuv4、uuv4_angled。先执行 asymmetric 的启动检查，然后完成其余构型。

1. trim：按上述构型顺序分配 seeds 8530–8537，各 256 个控制间隔（4.267 s）。
2. excitation：seeds 8540–8547，各 320 个间隔（5.333 s）；只对 trim 的完整语义检查及末尾运动门限通过的构型执行。
3. excitation 的前 128 个间隔为显式启动/稳定过程。其后四轴各 48 个间隔：12 个正脉冲、12 个零脉冲、12 个负脉冲、12 个零脉冲，seed 固定正负顺序。加速度幅度 `[4,2,1,.5]`，反馈全程运行。

最多 16 次原生采集、4,608 个控制间隔、9,216 个物理子步；累计采集上限 40 分钟，每次预留不超过 300 秒，计入失败；传输目录磁盘上限 1 GiB。一次失败不自动重试、不消费新的 seed；若改变规则，另起源版本和诊断协议。

## Stop / Go

保留 v27 的无接触、线速度 ≤1.5 m/s、角速度 ≤3 rad/s、倾斜 ≤60°、水平/竖直位移 ≤2 m 的逐物理子步门限。末尾 64 个物理子步线速度和角速度均 ≤0.5，倾斜 ≤30° 才准许该构型脉冲检查。停止或未通过的前缀不进入训练。

源代码包、根目录和独立克隆测试、锁定 Isaac 版本和补丁、实际加载路径、原始状态/命令/接触记录、归档清单和本地独立重算全部通过后，才能报告校准结果。跨 CPU 不重跑优化器来要求完全相同的迭代路径；独立重建目标和已发命令的物理残差，门限不变。

全部 case 的 role 都是 calibration，training_eligible=false，model_fits=0。即使通过，也只能说明这些短时工作点可以采集；下一步仍须冻结独立 fit/validation 划分与持续激励规则，先检查可辨识性，再比较 persistence、线性诊断基线及 Koopman 模型。
