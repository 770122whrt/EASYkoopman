# R53冻结残差：为什么部分构型越修越差

2026-09-27。18个冻结模型、24条历史fit轨迹；零新拟合、零求解、零仿真。计算13.20秒，输出约9.1MiB。四项专项测试通过。结果是开发数据上的同起点单步诊断，不是新盲测或闭环结论。

**主要发现：训练总体改善不等于每个构型改善；留构型时，角速度修正尤其容易外推失真。** 两个lambda的8个LOCO留出构型，角速度单步RMS都高于匹配物理基线。heavy/asymmetric尤为明显，且有具体的有害读出组；普通构型的差别通常小得多。

## 怎么算，为什么能定位修正方向

每个记录步都使用同一真实起点、同一机械参数及同一已记录执行器加速度。目标为下一步的世界系线速度、机体系角速度，扣去两模型共同的已知输入。记该目标为y，物理速度读出为Kp，冻结学习增量为ΔK：

`eP = y - ψ Kp`，`r = ψ ΔK`，`eR = eP - r`。

逐轴加权均方误差严格满足：

`MSE(R) - MSE(P) = mean_w(r²) - 2 mean_w(eP·r)`。

修正太大，或与物理误差方向不一致，就增加误差。前256步权重1/3、后384步权重1，完全沿用冻结训练；线速度与角速度分别报告，不混成无量纲不明的总分。下表三轴RMS指各轴MSE之和再开方，因此比值不依赖三轴是否再除以3。

全部162组统计的恒等式最大绝对残差为8.47e−22。18个模型的源轨迹哈希、源特征/目标/权重字节哈希、训练标准化参数及原训练RMSE全部复核通过，没有重新训练或改变旧记录。

## 两个突出问题，不靠最大z-score猜原因

**heavy_moderate：** 源训练中欠激励的平动二次阻力特征，在留出构型上激活达约3509个源训练标准差。该组的自由角速度读出产生明显过大的修正。按中心化分组的误差增量分摊，平动二次阻力组是角误差增加的最大贡献者，两种lambda都如此。λ=.001比λ=.1更严重。这里指错误的平动特征→角速度学习交叉项，不是说真实平动二次阻力不该存在。

**asymmetric：** restoring_x/y的学习修正外推，恢复力矩组主导角误差增加；λ=.001三个角轴的物理误差与修正相关均为负，方向没有对准应修复的误差。restoring_y最大源标准化幅度约351。restoring_z幅度更大（约1.60e6），但对应六个ΔK系数和输出贡献严格为0，因此不能把它当作残差错误的直接原因。

这与[v81较少起点、λ=.1的多步消融](../learned-velocity-v81-20260926/loco-root-cause/README.md)方向一致；本次扩展到全部单步、两种lambda，仍是同一批历史数据，并非独立新实验复现。

原始特征贡献受均值/常数相互抵消影响，所以结果同时保存原始组和源均值中心化组。中心化用`(ψ−mean_source)ΔK`，另保留`mean_source ΔK`偏置，使总修正完全不变。分组误差增量采用`mean_w(r_g*r−2eP*r_g)`，包含交叉项且可相加；另给出单组移除后的误差变化，二者不能混淆。此类单步干预不等于重新拟合后模型，也不证明闭环因果。

## 对下一步的直接意义

1. Rc应检验限制缺乏动力学/数据支持的交叉读出，不能只删特征数量或只增大ridge。
2. 必须同时看源训练、留出构型及多步预测；训练总RMSE改善不能作为控制准入依据。
3. LK的连续提升传播仍需要独立实测，本结果没有运行LK，不能预判其优劣。
4. pooled模型在uuv4历史单步角速度略退步（约2.4%–3.7%），而v82短闭环跟踪曾改善。这恰好说明单步误差表不能替代闭环收益检验；任务分布、多个状态指标及求解器质量仍需分别检查。
