## 不能将首轮负结果等同于路线失败

1. **正则先验不同。** LK拟合整组提升特征增量，向恒等映射收缩；R53仅拟合强物理先验周围的小残差。两个模型复用λ=.001/.1不等于相同有效约束强度。应先做来源数据上的有限λ校准，再讨论该LK候选能否发挥作用。
2. **回归自由度与机械描述秩受限。** 字典38维，回归设计490列。pooled只有8种机械配置；含常数的10列机械描述组合，其独立秩至多8，设计必有相关方向。标准化不能消除这种辨识限制；不得把490列误称为490个独立有效方向。
3. **有限字典不精确闭合。** 即使`v_next = v + dt*a`，也有`v_next² = v² + 2*dt*v*a + dt²*a²`。当前加性`Az+B[a,a²]`没有显式状态×输入项，无法精确表达此例中的全部平方特征更新。这是有限近似的结构边界，不是A/B拼接bug，也不否定线性提升预测的一切形式。
4. **物理知识和拟合目标也不同。** LK学习位置/姿态/速度及高阶特征的变化；R53保留解析运动学和已知输入映射。两者差值不能全部命名为“线性传播收益/损失”。
5. **输出缩放并未改变独立ridge解。** 在当前各输出共享同一Gram和λ、互不耦合的闭式回归中，先除`output_scale`、解线性方程再乘回，代数上抵消。不应将这一步描述成改善多输出权重平衡。

已记录pooled λ=.001的80步姿态RMS：普通LK 6.710mrad，使用同一个算子的每步重提升诊断6.314mrad，匹配物理0.08394mrad。重提升只带来有限改善，故当前误差不能全部解释成离开提升流形；单步拟合、字典和正则也需要检查。λ=.1原姿态RMS32.538mrad，首轮两个LK候选均不能凭此进入既定4mrad窗口门。

后续建议限于同一LK族：保留首轮负结果，在来源开发划分上做有限λ校准，检查训练设计条件和关键动力学系数；外部留出构型不得参与选择。不要据本记录扩为新模型架构，也不要将来源校准后的结果称为新盲测。
