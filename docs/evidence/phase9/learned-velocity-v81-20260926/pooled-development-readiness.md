# Pooled v81：开发性闭环适用性

结论：两个 pooled 候选均有理由进入带原安全门的小范围、已知构型开发性闭环。是否略差于几乎精确的物理模型，不应直接替代安全判断；相对收益应由同一MPC的配对闭环测出。

证据为24条历史 fit 轨迹上的回代：每构型3条×3起点，每窗口80物理步。两个模型各72/72窗口完整。它不是独立验证，不证明泛化；LOCO尤其heavy_moderate的负结果仍然有效。
