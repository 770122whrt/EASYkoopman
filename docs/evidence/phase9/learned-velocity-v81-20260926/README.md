# v81：真正学习速度读出后的结果

当前结果是 `normalized-quaternion/report.json`。上层首轮结果保留，但姿态角误差计算未归一化实测四元数，会出现虚假的误差地板；不得使用其姿态指标。修正已由反例测试验证。两轮训练矩阵完全相同，只有评估姿态指标修正。

## 实现与界限

- 原投影模型的速度矩阵被 D/Q 物理结构覆盖。新模型直接学习 53×6 的速度读出，不再覆盖为 D/Q；解析位姿积分、执行器及已知控制输入映射保留。
- 名称为 **projected controlled EDMD**；不声称完整潜空间闭合。新的独立模型 schema 不是旧 v30/v38 准入记录。
- NumPy 和 CasADi 的接口共享同一个学习矩阵（`prepare_learned(...)._symbolic_base`）。本目录测试尚不包含实际 CasADi 求解或闭环。
- 每个 fold 从相同 fit 数据重新辨识物理中心。两个事先固定的 ridge 值 0.001 和 0.1 均保留，不从留出构型选择胜者。
- pooled 使用24条历史 fit 轨迹，是训练集回代。8个 LOCO fold 各使用21条训练、3条留出；标准化、物理中心不接触留出数据。已知构型机械参数仍提供给预测器，不能声称未知机械参数泛化。
- 预测从256/384/512三个固定起点开始，回放相同已记录执行器加速度；不读取后续真实状态来纠正预测。评估1/80/128个物理步，不等价于闭环控制效果。

## 结果

所有学习矩阵均超出 D/Q 的仿射子空间；pooled 距离为1.612（ridge 0.001）和0.0753（ridge 0.1），已确认模型形式真正分离。

下表为8构型留出预测的80步（0.667秒）结果，共72个固定窗口：

|预测器|完整窗口|姿态RMSE rad|线速度RMSE m/s|角速度RMSE rad/s|
|---|---:|---:|---:|---:|
|学习读出，ridge 0.001|72/72|0.010602|0.001183|0.024122|
|学习读出，ridge 0.1|72/72|0.003389|0.000311|0.006829|
|同数据辨识物理|72/72|0.00008456|0.00002402|0.00011477|
|名义物理|72/72|0.00008574|0.00002435|0.00010905|
|状态保持 persistence|72/72|0.050584|0.022893|0.143891|

128步时，ridge 0.001 有1/72窗口预测越界（heavy_moderate）；失败单列保留，其他71个窗口的平均值不能掩盖这次失败。ridge 0.1全部72个完成。pooled回代里，学习读出的主要汇总指标也未超过同数据物理。

**结论：学习模型能预测，并且明显好于 persistence；但当前没有独特 Koopman 表示收益，也不能宣布已有可靠跨构型控制泛化。** long_body 留出场景 ridge 0.1姿态误差略小于物理，但角速度略差，不能把单项改善写成整体胜出。

heavy_moderate 被留出后，其二次阻力相关特征可达到训练特征标准差的1284–3509倍（拟合尺度下限为1e-6）。这是外推风险的直接证据，不是已经证明全部误差的唯一原因；见 `feature-extrapolation.json`。

## 推荐

先完成独立控制链验收及反馈预演的闭环对照。新学习模型不得凭“矩阵不同”自动晋升：应过预测与约束门后，才进入同一MPC的开发性小范围比较。当前负结果支持保留物理中心与适当结构约束；未来若增加数据，应针对未覆盖动力学区域，而不是把最终测试数据偷偷用于训练。

本地验证：65项测试通过，见 `local-tests.xml`。两轮训练与评估墙钟合计194.36秒，新增文件低于128MiB。两轮模型/失败均保留；无新服务器物理运行，无测试角色训练，无旧模型覆盖。
