# LOCO失败的实际残差来源

结论：两个困难构型的问题来源不同。heavy_moderate主要来自学习到的“线速度二次阻力特征→角速度”交叉项外推；asymmetric主要来自恢复力矩x/y方向特征上的学习残差。**不能只看特征标准化值大小来判断根因。**

本诊断固定ridge=0.1、两个预指定构型、每构型3条留出轨迹×3个固定起点，预测80物理步。将53个特征预分为12个物理意义组，分别仅移除该组学习增量ΔK，保留原物理贡献和其他学习项。全部组的结果和失败均保留；没有拟合、模型选择、部署或服务器运行。

## heavy_moderate：外推放大了不可靠的交叉项

在9个真实起点，`axis_quadratic_1_0`的训练标准差只有9.66e-7，归一化用了1e-6下限；留出构型的标准化幅度达到3328。它却学到了到三个角速度输出的增量系数约 `[0.1806, 0.2827, 0.0782]`。`axis_quadratic_1_1`、`axis_quadratic_1_2`也有显著角速度贡献。

线速度二次阻力组在真实起点造成的额外角速度输出范数最高0.001772 rad/s/步。整个组仅作用在线速度误差上的最大贡献约1.20e-6 m/s，说明主要问题是它的**角速度交叉读出**，而不是其原有平动阻力作用。移除这一组学习增量后，姿态误差下降约92.5%、角速度误差下降约92.9%。其他单组干预没有相近改善。

这支持该组是本回放条件下主要误差源；剩余误差仍高于物理，不能说唯一原因已经穷尽。交叉项是否在其他真实系统中有意义是另一个问题，此处不能根据训练相关性给它跨构型外推能力。

## asymmetric：恢复力矩x/y残差有问题，z项不是原因

`restoring_body_1`的训练标准差约0.03284，留出构型标准化幅度约350。其学习角速度增量以y输出为主，系数约−4.33e-6；`restoring_body_0`也贡献一部分。恢复力矩组真实起点的净额外角速度范数最高4.73e-5 rad/s/步，在递推中积累。

移除恢复力矩组的学习增量使姿态误差下降83.4%、角速度误差下降88.1%，回到matched物理附近。

特别复核：`restoring_body_2`的标准化幅度虽然约743846，但其训练方差严格为0，学习增量六个系数也严格为0，因此 `phi_i * ΔK_i` **严格为0**。巨大z-score在这里反映未见特征，不构成预测误差的直接原因；先前仅凭它的外推倍数作根因解释是不成立的。

## 为什么不能只看最大的原始项

姿态/高度组和常数项的原始贡献各有约1e-3量级，但彼此强烈抵消：heavy_moderate两者合计的最大角速度贡献约6.18e-6，asymmetric约7.89e-7。分别删掉任一组反而明显变差。因此报告同时保留原始贡献和减去训练均值后的贡献，不将大系数或大原始项直接视为坏项。

下一步若修模型，依据应是限制缺少数据支持的自由交叉残差、补充相应动力学覆盖，并在新数据上验证；不能直接把本次消融结果当作已经训练和验证的新泛化模型。
