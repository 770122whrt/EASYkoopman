# 跨控制器回顾性命令预测验证

使用已认证的base、uuv4、long_body、uuv6历史反馈闭环轨迹。每条在物理步4、80、160开始预测未来80步；各预测器共12个窗口。两份pooled模型及同记录的物理prior均不重新拟合，模型和轨迹hash保存在result.json。

输入严格为当前状态、已经执行的完整命令历史，以及离线条件预测指定的未来20条pre-TAM命令。未来加速度由模型自己的执行器递推产生；未来真实状态只用于评分。没有把真实未来加速度或真实未来状态送进预测器。

这4条控制轨迹不是本次模型拟合轨迹，但曾用于项目开发，因此这是跨控制器的回顾性验证，不能称为新盲测、在线oracle或闭环收益证据。

|预测器|完整/总窗口|深度RMSE μm|姿态RMSE mrad|角速度向量RMSE rad/s|预测支持域越界|
|---|---:|---:|---:|---:|---:|
|learned_0.001|12/12|1.0791|0.1274|0.00004814|0|
|learned_0.1|12/12|1.0755|0.1253|0.00004915|0|
|matched_physics|12/12|1.1214|0.1209|0.00006348|0|

两个学习模型的深度和角速度预测优于matched物理，姿态预测略差。例如ridge 0.1的角速度RMSE降低约22.6%，深度降低约4.1%，姿态增加约3.6%。全部指标绝对误差很小，不能把这些相互不同的改变量拼成已证实的整体控制收益，也未选择某个lambda作为获胜者。

这补充了训练集回代以外的控制状态分布证据，支持受约束的开发性2秒闭环试验；LOCO泛化负结果仍保留。

全部36条预测完整，预测状态与实际未来状态均在共同支持域内。因果历史重建转子速度与观测最大差1.36e-5，符合原1e-3回放容差；12个预测起点时钟与观测完全一致，见clock-verification.json。

资源：零拟合、零服务器运行；主体评测4.16秒、结果约1.11MB，低于5分钟/32MiB限制。result.json保留每个窗口分项均值/最大值/RMSE、失败计数、支持检查和预测序列。
