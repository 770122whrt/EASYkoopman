# 固定基础构型后的提升模型诊断

2026-09-27，用户明确选择“先做单构型提升诊断”。结论：**同一构型换激励也未通过，所以不能把目前失败只归因于跨构型。训练覆盖不足有直接迹象，但还不能认定唯一根因。**

基础构型的代码名为base。用伪随机切换输入（PRBS）和多正弦输入（multisine）两条历史轨迹训练，将扫频输入（chirp）轨迹留出、不参与训练。维持38维非线性提升及原输入/误差门；固定A/B与双线性各5个事先声明的λ。没有普通线性模型，没有用留出成绩选择部署模型，没有新仿真。全部10个模型只含两个训练轨迹哈希，机械context均为常量。

λ约束训练系数，数值越大通常越抑制大系数；它不是误差或控制周期。两类模型都先构造非线性特征，不是直接对原始状态做普通线性预测。详细解释见[统一报告](../../../phase9_model_comparison_v84_report.md)。

## 数据覆盖诊断

仅以训练状态逐坐标取值范围作事后描述，不把它追加为新准入门：

- 机体系x方向速度训练范围−0.001909至0.000514m/s，chirp达到0.004302m/s，55.47%样本超出训练范围。
- 机体系y方向速度训练范围−0.003763至0.000912m/s，chirp达到0.008536m/s，44.22%样本超出训练范围。
- 姿态局部x/y坐标分别约17.03%/16.88%样本越出训练取值范围。
- 高度虽然有32.19%样本越出训练范围，但模型增量刻意不依赖绝对高度，不能直接拿高度越界解释误差。
- 固定模型有效设计49列、数值秩48；双线性265列、数值秩224，按相对1e−6阈值的有效秩为190。新增项存在明显依赖/弱辨识方向；条件数/秩只是诊断，不是单独的因果证明。

## 后续建议

先核对训练激励是否覆盖计划控制的速度/姿态区域、剔除确定冗余或约束已知积分关系，再用预先冻结的新轨迹验证。不要继续依赖留出chirp成绩选择λ，也不要仅靠增加特征或重复训练同一小数据集。若补采数据，应先定义训练覆盖目标和独立验证激励；模型门通过后再做2秒控制。
