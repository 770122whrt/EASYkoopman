# v34：完整状态读出与一致重新提升

2026-09-13。承接[v33固定负结果与阻力反例](phase8_4_controlled_lift_v33_results.md)。本轮唯一候选不新增矩阵拟合，只修改已有v33九个模型的递推读出。先做本地source与24fit全目录检查，未批准/启动新正式采集，不访问旧24test。

## 要修复的机制

完整提升状态可以离开物理观测量关系，使二次阻力对当前速度产生正功，非负D/Q也不能阻止。固定base反例中恢复二次阻力观测量后，原第39子步失败改为完成120子步。这个结果只支持候选设计，不能外推其性能。

采用完整的状态读出/重新提升，而不是只修一个阻力组，理由是旋转、速度与其余物理特征也有一致性关系。有限Koopman近似中的投影有文献依据，坐标投影只使用状态输出也与方程辨识相关，不承诺完整A全部列都带来贡献。[原始论文第4节](https://arxiv.org/html/2307.16188v1)。

## 唯一候选的精确定义

每个物理子步：

1. 用当前预测状态及该构型实际参数得到`z=psi_c(x)`。
2. 用原v33固定矩阵及其完整步输入映射得到`z_tilde = z A_33 + Delta_33(x,a;c)`。
3. 高度取`z_tilde[0]`；R9经最近SO(3)投影得到姿态；世界速度转回该新姿态body坐标，body角速度按已声明观测量读出，组成下一预测状态。
4. 下一步从该状态重新提升。新的二次阻力、恢复力、陀螺项和其他观测量都对应同一个预测状态。

输入映射仍为`psi(F_theta(x,a))-psi(F_theta(x,0))`，仅使用当前预测状态、因果可得作用输入和原固定D/Q。既不把真实下一步状态作为输入，也不在中途重置到真实轨迹。

与v30的实质差异：v30只用六个速度输出并由解析运动学生成位姿；v34使用A中**学习到的高度、R9和速度输出**，不以解析位姿替代。代价是这些学习输出也可能产生泛化误差，必须实测。投影后非状态输出不独立递推，因此不得声称完整53维自由递推稳定，或把剩余提升行的拟合归为额外收益。

这属于明确的受控、状态投影有限近似，输入映射非线性，仍不满足常数A/B线性QP-MPC合同。若有后续控制实验，应据实际模型选择优化方法并计入两次参数模型输入映射的计算成本；不能继承经典线性Koopman-MPC的速度优势。
