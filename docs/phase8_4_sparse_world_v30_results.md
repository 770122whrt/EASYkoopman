# Phase8.4 v30：拟合完成，独立验证准备

2026-09-13。当前完成了新数据适配、覆盖审查和34个固定候选拟合；下面的数字全部来自fit，不能称为独立验证成功。模型与评分规则冻结后，才开放预定16条validation。旧正式NO_SELECTION、24条未采test和r16校准身份不变。

## 当前判断

补齐真实物理参数、逐子步命令与执行器历史，并使用正确的坐标/位姿更新后，非线性候选的单构型、混合和留一构型预测在fit上均接近已知物理基线。因此，“单模型好、跨模型必然差”不是目前证据支持的结论。

跨构型原先存在多个混杂来源：物理参数传递错误、初态/执行器历史不一致、反馈状态依赖和不合理的速度跨项。当前heavy的状态仍有明显外推，但参数化物理项可以解释这部分动态。轴对齐覆盖统计本身不能判定模型必然失败。

新的候选以世界线速度和body角速度为固定观测量，学习受约束的阻尼系数；非速度提升行另有完整矩阵。主预测每一步做几何投影与重新提升，所以只能称为受控、投影的有限维近似。完整矩阵存在不稳定特征值，暂不支持稳定线性Koopman-MPC交接。

persistence在这里就是把预测起点的11维状态保持不变：未来每个时刻都预测当前高度、姿态、线速度和角速度。短区间动态小，它会很强；旧模型如果额外引入错误坐标项或初始执行器误差，就可能输给这个零变化基线。

非线性pooled完整矩阵谱半径约1.429，heldout-heavy约1.346，线性pooled约1.162。完整矩阵不投影的递推必须单列，不能用主预测的投影结果掩盖它。非线性主要阻力倍率接近已知物理先验1；局部弱激励轴仍有参数不可辨识，尚未证明学习相对已知物理有增量收益。
