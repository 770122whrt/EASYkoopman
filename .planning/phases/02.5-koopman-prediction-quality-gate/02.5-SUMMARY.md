# Phase 2.5 Summary: Offline Koopman Model Qualification Gate

**Date:** 2026-07-01
**Branch:** `isaaclab2-migration`
**Status:** Local implementation complete; server log gate still pending

## Result

Phase 2.5 now implements an Isaac-free model qualification gate before Koopman+MPC integration.

The local workflow is:

```text
validated JSONL logs
-> log-level train/validation/test split manifest
-> direct-state and paper-style lifted EDMD sweep
-> persistence and simple linear baseline comparison
-> divergence-aware multi-horizon validation
-> selected_model_manifest.json
-> gate_report.md
```

## Completed Work

- Added `koopman/splits.py` for explicit log-level split manifests and data-insufficient errors.
- Added `koopman/observables.py` for paper-style EasyUUV observables.
- Added `koopman/lifted_edmd.py` for lifted-space EDMD with `f[k+1] = Theta^T f[k]`.
- Added `koopman/baselines.py` for persistence and simple linear baselines.
- Added `koopman/normalization.py` for standard normalization artifacts.
- Extended `koopman/edmd.py` and `koopman/model.py` with optional normalization while preserving existing direct-state behavior.
- Extended `koopman/evaluation.py` with multi-horizon RMSE, attitude RMSE, max error, non-finite counts and divergence flags.
- Added `koopman/sweep.py` for candidate training/evaluation/ranking.
- Added `koopman/selection.py` for selected model manifest generation.
- Added `koopman/gate_report.py` for markdown gate reports.
- Added CLI workflows:
  - `workflows/split_koopman_logs.py`
  - `workflows/sweep_koopman_models.py`
  - `workflows/select_koopman_model.py`
  - `workflows/write_koopman_gate_report.py`
- Added fixture tests for all Phase 2.5 modules.
- Added server runbook: `docs/phase2_5_koopman_gate_runbook.md`.

## Phase 3 Entry Rule

Do not start MPC integration unless:

- `selected_model_manifest.json` exists,
- `gate_report.md` exists,
- `gate_status` is `pass`,
- the selected model beats persistence and simple linear baselines,
- held-out validation/test rollouts do not diverge.
