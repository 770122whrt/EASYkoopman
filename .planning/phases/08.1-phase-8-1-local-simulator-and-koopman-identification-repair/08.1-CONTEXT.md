<decisions>
## Implementation Decisions

### Version and isolation

- D81-01: experiment ID 固定为 `phase8.1-main-identification-v1`。
- D81-02: transition version 固定为 `easyuuv-koopman-transition-v2.1`；旧 schema v2/module/fixture/bytes 不修改。
- D81-03: v2.1 使用独立 modules、validators、collector/workflow 和 protocol directory；不存在隐式 v2→v2.1 upgrade。

### Actuator timing and memory

- D81-04: reset 后 previous end time 与 actuator-local clock 均为 0；每个 physics substep 用结束时刻更新，首 substep 获得完整 `physics_dt`。
- D81-05: schema 字段唯一为 `actuator_memory_4`，文档称 `causal filtered-virtual-control proxy`。
- D81-06: 唯一 recurrence interface 为 `reset/current/advance`；Bridge、validator、dataset、rollout 复用，不复制公式。
- D81-07: memory binary64、精确零 reset、mask-before-update、disabled input nonzero fail closed；uuv4* yaw精确零。
- D81-08: provenance 精确记录 `physics_dt_s`、integer `decimation`、`control_dt_s` 并验证乘积；role proposal 冻结 memory 初值全零、zero warm-up 和未来真实采集证据级别 `server_isaac_smoke`。
- D81-09: proxy 不等于真实 motor thrust/PWM/wrench/actuator state，也不保证整个 plant 严格 Markov。

### SO(3) and observables

- D81-10: quaternion `[w,x,y,z]`、Hamilton、body-to-world、body-right increment；R6为 rotation matrix 前两列 column-major。
- D81-11: target 固定为 10D increments `[Δdepth,Δv_b3,Δω_b3,δθ_body3]`；orientation 通过 Log/Exp 群复合。
- D81-12: principal Log、q/-q canonicalization、near-zero series、π-axis deterministic tie-break；正常 rollout 禁止 arbitrary quaternion projection。
- D81-13: observable 仅 `so3_identity_v1` width22 与 `so3_kinematic_v1` width56；34D lift 顺序由 SPEC 冻结。
- D81-14: identity 与 SO(3) simple-linear 属于同一 estimator equivalence class；ledger必须声明。

### Structured conditional

- D81-15: conditional 标识唯一为 `structured_pca2`；physical input 仅冻结的19D core facts；每折仅七source configurations等权 population normalization，scope=`loco_source7`。
- D81-16: zero variance columns移除；deterministic covariance eigenspace/tie/sign；PCA r=2、no whitening，不进入 grid。
- D81-17: `φ_linear_nonbias` 精确21D；conditional widths identity66/kinematic100。
- D81-18: rank tolerance `eps64*max(n,width)*sigma_max`；pre-ridge full rank required；ridge含bias；regularized Gram condition≤1e8；effective rank只记录。
- D81-19: rank/condition只作为algebraic/numerical admission，不证明physical identifiability或OOD generalization。

### Evaluation and release

- D81-20: source ledger在primary freeze前sealed；held-out descriptor diagnostic在freeze后独立生成、selection-ineligible且selector不可读取。
- D81-21:状态机固定为 source grid→source ledger→primary freeze→heldout diagnostic→expert fit/validation selection/freeze→test authorization→test open。
- D81-22: held-out expert C/fit拟合、C/validation独立选参、无conditional features、独立namespace、永不promotion；failure不阻止primary test。
- D81-23: source-per-configuration 固定 `report_all_no_ranking`。
- D81-24: final refit只接收 `selected_family`；outer test只决定family；all-eight fit/validation重新selection；conditional PCA scope唯一为 exact-eight `final_refit_all8`；zero test reads，atomic publication。

### D-23 and evidence

- D81-25: 只实现approval record schema/validator，不生成真实record。缺 canonical record 时正式入口 fail closed。
- D81-26: record只证明protocol hashes+explicit decision+experiment ID绑定；`attestation_scope=protocol_hash_decision_binding_only`、`identity_assurance=none`。
- D81-27: design approval不是D-23 approval；protocol proposal保持`pending_d23/proposal_only`。
- D81-28: old test只用于历史诊断；不得用于任何v2.1 feature/grid/gate/tuning。
- D81-29:正式结论仅限fixed exact-eight catalog内新轨迹LOCO；其余claims按SPEC禁止。
- D81-30: v2.1 official rollout divergence thresholds 继承 Phase 8 的 depth/linear/angular `100/100/100`，payload/hash 进入 analysis policy，正式 rollout 不接受调用者替换。

### the agent's Discretion

- 在不改变上述类型/语义的前提下选择 Python dataclass、immutable mapping、atomic writer 和 reason-code 的具体内部组织。
- 为减少重复可复用旧 v2 纯函数，但任何公开v2.1 validator/entrypoint必须精确检查v2.1 version，不可使旧v2接受新bytes。
- targeted tests的文件拆分和fixtures可按现有项目惯例组织；不得降低批准的容差、gate或隔离强度。

</decisions>
