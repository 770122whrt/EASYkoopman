## Frozen Transition Timing and Actuator Recurrence

每一条 v2.1 transition 必须严格对齐为：

```text
(state_11[t], actuator_memory_4[t], virtual_control_4[t], state_11[t+1])
```

其中 `actuator_memory_4[t]` 是施加本行 `virtual_control_4[t]` **之前**的状态。Bridge 先读取 `current()` 形成该行，随后才用已经应用 configuration control mask 的 `virtual_control_4[t]` 调用 `advance()` 形成 `actuator_memory_4[t+1]`。首行在 reset 后精确为零；unrecorded warm-up 为零。不得读取 future control、future memory truth、simulator actuator truth、PWM、applied wrench 或 environment oracle。

唯一 recurrence 为：

```text
alpha = exp(-control_dt_s / tau_s)
m[t+1] = alpha * m[t] + (1 - alpha) * masked_virtual_control[t]
```

reset 固定 `actuator_state=0`、`previous_end_time_s=0`、`actuator_clock_s=0`。physics substep 使用：

```text
end_time_s = actuator_clock_s + physics_dt_s
actuator_state = update(command, end_time_s)
actuator_clock_s = end_time_s
```

对一个 control interval 内恒定 command 和整数 `D=decimation`，解析闭式为：

```text
state_after_D = exp(-(D*physics_dt_s)/tau_s) * state_before
              + (1-exp(-(D*physics_dt_s)/tau_s)) * command
```

provenance 必须保存 `physics_dt_s>0`、正整数 `decimation` 与 `control_dt_s>0`，并以 binary64 验证 `control_dt_s == physics_dt_s*decimation`。解析测试独立计算期望值，不调用生产 `advance()`。

## Frozen SO(3) Conventions and Numerics

- quaternion 顺序为 `[w,x,y,z]`，使用 Hamilton product，表示 body-to-world rotation；`R6=[R00,R10,R20,R01,R11,R21]`。
- 训练增量严格为 `delta_q=canonicalize(normalize(inverse(q[t]) tensor_product q[t+1]))`，`delta_theta_body=Log(delta_q)`；预测严格为 `q_pred[t+1]=q_pred[t] tensor_product Exp(delta_theta_pred)`，即 body-right increment。
- 输入 quaternion 必须是 shape `(4,)` 且全 finite；Euclidean norm `<1e-10` 或 `abs(norm-1)>1e-6` 时以 `quaternion_invalid` fail closed，只有通过该输入 gate 后才以 binary64 归一化。
- `canonicalize(q)` 先令 scalar part `w>=0`；当 `w==0` 时，取 vector part 中绝对值最大的 component（并列取最低 index）为正。因此 `q` 与 `-q` 产生相同 target，并在正好 180° 时得到唯一 axis sign。
- principal `Log` 使用 `theta=2*atan2(||v||,w)`，范围 `[0,pi]`，返回 `theta*v/||v||`。当 `||v||<sqrt(eps(float64))` 时使用 `2/w - 2||v||^2/(3w^3)` 的 scale series；零向量返回精确零。
- `Exp(delta_theta)` 使用 `[cos(theta/2), sin(theta/2)*delta_theta/theta]`；当 `theta<sqrt(eps(float64))` 时 vector scale 使用 `1/2-theta^2/48+theta^4/3840`。
- Hamilton composition 后若 `abs(||q||-1)>1e-10`，以 `quaternion_unit_norm_drift` fail closed；预算内仅允许 binary64 roundoff renormalization，不得把大幅 quaternion projection 当作正常模型路径。

`tensor_product` 在上述公式中表示 Hamilton quaternion product，不表示 feature Kronecker product。

### Source-only normalization and deterministic PCA

令冻结 source configuration 顺序下的 descriptor matrix 为 `X in R^(7x19)`。每个 configuration 恰有一行，因此权重完全相等。对 column `j`：

```text
mu[j]    = (1/7) * sum_i X[i,j]
sigma[j] = sqrt((1/7) * sum_i (X[i,j]-mu[j])^2)
```

binary64 下 `sigma[j] == 0` 的 column 确定性移除；其余列按原 feature index 保持顺序，并形成 `Xn=(X-mu)/sigma`。令 centered `Xn` 的 singular values 为 `a1>=...`，affine-rank tolerance 精确为 `eps(float64)*max(7,retained_width)*a1`（全零矩阵的 rank 为零），affine rank 是超过该 tolerance 的 singular-value 个数。若保留维度少于 2 或 affine rank 小于 2，则以 `descriptor_affine_rank_below_required` 拒绝 conditional family。

PCA covariance 固定为 `C=(1/7)*Xn^T*Xn`，使用 symmetric eigendecomposition，按 eigenvalue 降序取 `r=2`，不 whitening。eigenvalue tie tolerance 为：

```text
tie_tol = eps(float64) * max(7, retained_width) * max(1, abs(lambda_max))
```

差值不超过 `tie_tol` 的 eigenvalues 属于同一 eigenspace。该 eigenspace 的 basis 由其 orthogonal projector 依次投影 retained-feature-order 的 canonical unit vectors，并以 modified Gram-Schmidt 构造；residual norm 必须严格大于 `basis_tol=eps(float64)*max(1,retained_width)` 才接收，否则跳过该 axis。这样不依赖 eigensolver 返回的任意旋转。每个 component 的最大绝对 loading 必须为正，并列时取最低 feature index；components 最终按 eigenvalue group、再按上述 canonical basis 次序排列。held-out descriptor 不得参与 `mu/sigma/C/eigenspace`；freeze 后 diagnostic 只能复用 frozen transform。

### Solve-design admission numerics

`standard_v1` normalization 保留 bias column 为精确 `1`，只对其余 design columns使用 source-fit rows 的 population mean/std；零 scale 使用 `1`，并由随后的 rank gate 判断。`none` 不改变 design。ridge penalty 包含 bias。

对实际送入 ridge solve 的 normalized design `D in R^(n x w)`，令 singular values `s1>=...>=sw>=0`（不足 `w` 的尾部视为零）：

```text
rank_tol = eps(float64) * max(n,w) * s1
design_rank = count(si > rank_tol)
p_i = s_i / sum_j s_j  for positive s_i
effective_rank = exp(-sum_i p_i*ln(p_i))
regularized_condition = (s1^2 + ridge) / (sw^2 + ridge)
```

全零 design 的 `effective_rank=0`。candidate admission 精确要求 `design_rank==w` 且 `regularized_condition<=1e8`；condition 使用实际 solve design 与该 candidate 的 ridge。`effective_rank` 只记录。rank/condition 是 algebraic/numerical stability gate，不证明物理可辨识性或 descriptor OOD 泛化。
