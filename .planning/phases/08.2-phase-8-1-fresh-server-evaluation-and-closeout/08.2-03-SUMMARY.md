## Outcome

Eight independent formal LOCO folds completed with a machine-enforced pre-test freeze; the frozen outer selector published a pathless `NO_SELECTION`. Both eligible families failed the frozen baseline gates: pooled Koopman remained numerically identical to simple linear, and the conditional family failed closed in all eight folds.

## Execution

- Evaluator source commit `1151b21`, dataset source commit `4f3b4cb`, D-23 role/analysis protocol hashes unchanged from Phase 8.1 approval.
- Each of the eight held-out configurations ran as one independent Python process executing `workflows/run_koopman_v21_loco.py` with per-fold staging and atomic publication into the non-canonical work root `.pytest-tmp/phase8-2-formal-folds/<configuration>/`; no completed fold was ever recomputed.

Process segmentation/concurrency changes only scheduling, not protocol: each fold performs the frozen source7 fit/validation, source ledger seal, primary freeze, held-out diagnostic, expert freeze, test authorization and guarded held-out test independently, with identical CLI bindings to the checked-in chain.

## Deviations and claim boundary

- No protocol deviation: candidates, metrics, thresholds, bootstrap, freeze order and access semantics are byte-identical to the D-23 frozen protocol.
- Operational orchestration deviations (documented, non-protocol): (1) folds ran concurrently in eight processes instead of serially — per-fold process isolation is exactly what the plan requires; (2) the v4 orchestrator misread process exit codes and fail-closed after all folds completed — fold telemetry and envelopes confirm all eight folds succeeded with exit code 0, and assembly was completed by the checked-in script with `formal_fold_resume` for every fold; (3) earlier attempts were interrupted by host sleep/reboot and an agent-session shutdown before any fold completed; no partial fold was ever published.
- Allowed claim: fresh-episode prediction transfer within the fixed exact-eight catalog only. No closed-loop, environment, Agent, Sim2Real or hardware claim.
