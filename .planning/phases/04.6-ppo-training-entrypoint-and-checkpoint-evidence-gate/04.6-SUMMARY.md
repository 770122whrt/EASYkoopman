# Phase 4.6 Summary: Checkpoint Evidence Gate Complete

**Date:** 2026-07-04
**Branch:** `isaaclab2-migration`
**Status:** complete through server Isaac smoke gates

## What Changed Locally

Phase 4.6 now has the local code needed to restore the PPO/RSL-RL checkpoint evidence path under Isaac Lab 2.2.1.

Implemented:

- `workflows/train.py`
  - Migrated to the `isaaclab_app.AppLauncher` shim.
  - Registers `EasyUUV-Direct-v1` through the local task registration path.
  - Keeps the first PPO training path on `legacy/Ssurface`.
  - Uses the Isaac Lab 2.2 `parse_env_cfg(..., device=...)` signature.
  - Adds `--save_interval` so a short checkpoint-generation smoke can use `--save_interval 1`.
  - Writes a Phase 4.6 training summary with `result_bucket`, `ppo_evidence_level`, `selected_checkpoint` and `selected_rule`.

- `workflows/discover_ppo_checkpoints.py`
  - Adds deterministic checkpoint selection.
  - Returns `selected_checkpoint` and `selected_rule`.
  - Supports explicit checkpoint selection through `--checkpoint`.
  - Selection rule: explicit checkpoint first, otherwise newest `model_*.pt`, otherwise newest generic `*.pt`.

- `workflows/play_eval.py`
  - Migrated to the `isaaclab_app.AppLauncher` shim and `isaaclab_compat` imports.
  - Uses the Isaac Lab 2.2 `parse_env_cfg(..., device=...)` signature.
  - Keeps the legacy baseline path: `PPO checkpoint -> legacy/Ssurface -> 8D PWM`.
  - Writes Koopman JSONL plus a Phase 4.6 sidecar summary.
  - Sidecar labels the run as `result_bucket=legacy_ppo_baseline` and `ppo_evidence_level=checkpoint_smoke`.
  - Defaults policy export off via `--export_policy` so smoke runs do not block in JIT/ONNX export.

- `workflows/gen_policy.py`
  - Migrated to the Isaac Lab 2 compatible app/import pattern.
  - Preserves policy export behavior.

- `workflows/play_ppo_koopman.py`
  - Records `selected_checkpoint`, `selected_rule` and `result_bucket` for old-checkpoint adapter smokes.

- `tests/test_phase46_source_contract.py`
  - Adds local source-contract tests for Phase 4.6 training/eval/export migration.

## Evidence Boundaries

This phase proves:

```text
The PPO/RSL-RL training entrypoint can run under Isaac Lab 2.2.1.
A checkpoint can be generated and discovered.
The generated checkpoint can load through the legacy PPO evaluation path.
The same checkpoint can pass through the guarded Koopman-MPC adapter smoke.
```

It does not prove:

```text
PPO performance, convergence or superiority.
Lossless migration of an old PPO checkpoint to Koopman-MPC.
That the final Koopman-MPC PPO has been trained; Phase 5 owns that.
```

Those are Isaac server gates.

## Fixes Made During Server Verification

- `parse_env_cfg()` failed on Isaac Lab 2.2.1 when called with the old `use_gpu=` keyword. The Phase 4.6 workflows now call it with `device=getattr(args_cli, "device", "cuda:0")`.
- `play_eval.py` initially blocked before rollout because policy export was unnecessary for smoke. It now exposes `--export_policy` and keeps export off by default.
