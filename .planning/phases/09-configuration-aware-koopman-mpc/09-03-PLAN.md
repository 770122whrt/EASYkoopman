# 有界命令优化、支持域与非阻塞发令

前置：[路线审核](../../../docs/phase9_roadmap_review.md)、[09-02](09-02-PLAN.md)。v43只解决了部分预测开销，尚未完成实时准入。本计划先实现本地合同及完整求解计时，以此补齐09-02的调度决定；服务器执行仍须单独09-04方案。

## 架构选择及范围

- 采用有固定候选上限的4D短时域搜索，保留完整非线性投影递推、两子步hold和因果执行器记忆。它可以明确记录计算量、失败原因和模型对照；不称为全局最优解。
- 暂不接通用非线性求解器：迭代/失败开销和数值梯度尚未测量。暂不改为固定A/B的QP：当前模型没有获得该形式的资格。
- 不把已用来采集数据的FeedbackPolicy逆解直接塞入60Hz回退路径；该逆解包含多分支迭代。先测其成本，再决定能否使用。原Legacy/S-Surface仍作为独立比较器；其控制收益及稳定范围也须匹配验证。

本地实现已由用户授权。这里的候选数、权重和调度值是可检验的初始工程设定，不是已验证的控制效果；不利用正式test选参。

## 1. 先完成目标和准入合同

新增独立模块，不改v1控制器或v38–43冻结/已测接口。所有输入/输出明确为[z, qw,qx,qy,qz, vb(3), wb(3)]和[roll,pitch,yaw,depth]。

- 全可控姿态使用四元数符号不变的旋转角误差。uuv4/uuv4_angled只使用目标与当前的机体系世界竖直方向误差；移除偏航速度和偏航命令代价，不能仅给yaw命令置零而继续优化完整姿态。
- 回归必须包含：对当前姿态施加任意世界Z轴纯yaw旋转，在roll/pitch、深度及体速度不变时，uuv4姿态目标与总可控代价不变；同一变化对可控yaw构型仍产生代价。q/-q等价；无效四元数拒绝。该不变量同时用于优化目标和最终评分入口。
- 命令限幅、变化率、mask、原始未限幅PWM饱和分别检查；不能只看裁剪后的PWM。将约束参数作为显式只读输入，非法/不完整参数直接拒绝。
- 支持域来自仅fit角色的数据及明确物理边界，绑定构型/context/model/来源。按深度、姿态倾斜、体速度、角速度及命令范围记录；uuv4不可因全局yaw变化被错误拒绝。缺少真实fit来源时不准入运行，而不是以合成测试域代替。
- 支持域只是保守筛查，不声称概率保证或所有范围内闭环安全。预测任何一步越域、非有限或原始PWM饱和，整条候选失效，并记录首个失败区间/原因。

## 2. 完成有界候选求解并测全链路

第一版使用H=20控制区间：基准/平移后的warm-start序列，加每个可控轴的正负扰动，最多9条候选（欠驱动最多7条），仅一轮搜索。扰动只作用于未承诺的未来段；首版每轴步长和变化率通过显式配置提供，并在fit-only测试前固定，不能边看正式结果边改。

必须包含可行基准候选，选择可行候选中最低同一目标值；当无改善时保留基准，所有候选无效或超时则返回reason-coded失败。不得对失败候选赋有限低分。计划包含预测起点、构型/context/model/reference身份、真实已发历史版本、命令序列、支持域版本、成本和完成时间；trial状态不能写入live估计器。

最先做合成、可解释反例：已知响应下优选正确方向；不可控yaw不改变候选/选择；全部失效、NaN、超时和基准获胜；权重/目标改变产生预期响应。随后只用既有fit起点检查完整耗时，包括状态复制、基准/候选生成、分配和饱和检查、预测、评分、选择、序列化，不止测模型调用。

预设100ms只作为首轮完整求解的拒绝上限，不作为10Hz资格或尾延迟保证。记录所有失败和超时；第一轮若不满足，则给出NO_GO和具体热点，不能静默增加上限或缩短预测来伪造通过。首次编译和源/模型验证必须在worker READY前完成，不进入控制周期。另测实际fallback生成和仲裁时延；低层16.67ms预算不能被高层求解预算替代。

## 3. 非阻塞仲裁与因果切换

求解在独立worker，低层唯一发令入口不等待worker。输入、结果队列和未完成请求均有上限；worker未就绪、卡住、报错、晚到或重启时保持已准入的bounded fallback。先用故意阻塞的worker验证低层仍按周期返回；协作式deadline不充当隔离保证。

计划执行前核对episode/config/context/reference/model身份、实际已发命令前缀（原数值容差）、计划年龄以及当前观测与相应预测的偏差。不能把延迟返回的第0步当作当前命令，也不能把trial转速写回。低层只在收到实际发令确认后推进CausalCommandState。

较慢优化必须有明确的承诺前缀/激活区间和状态偏差门。没有可核对前缀或状态超门时丢弃计划，实际fallback覆盖旧计划后旧结果也必须失效。激活延迟、最长计划年龄和偏差值须依据步骤2完整计时及fit域写成固定参数后再做运行验证；当前不预先宣称10Hz或60Hz完成。

## 4. 完成证据与边界

通过本地目标、支持域、候选、失败/时序/隔离测试和完整成本实测之后，更新09-02的计算/调度结论。即使本地合同通过，MPC2-01..04也不能全勾选：还缺实际Isaac接口、匹配场景和闭环评价。不得把本地假worker或合成域称为服务器通过。

下一服务器提案要列明三类同优化器比较：名义物理、辨识参数物理、当前投影模型；另外列Legacy/S-Surface控制器对照。相同D/Q模型代数等价的结果不得包装成独特Koopman优势。新资源范围与停止门独立于v38已关闭预算。
