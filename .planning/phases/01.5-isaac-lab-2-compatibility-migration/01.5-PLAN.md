# Phase 1.5 PLAN: Isaac Lab 2.x Compatibility Migration

**Spec:** `.planning/phases/01.5-isaac-lab-2-compatibility-migration/01.5-SPEC.md`  
**Target branch:** `isaaclab2-migration`

## Plan

### 1. Planning Artifacts

Update the roadmap, requirements and state to make Isaac Lab 2.x migration an explicit phase between baseline data collection and Koopman identification.

Verification:

- Phase 1.5 appears in `.planning/ROADMAP.md`.
- `COMPAT-*` requirements appear in `.planning/REQUIREMENTS.md`.

### 2. Source-Contract Tests

Add local tests that do not import Isaac but verify the expected migration structure:

- Compatibility module contains Isaac Lab 2.x imports and old fallback imports.
- Direct controller starts `AppLauncher` before importing task/environment code.
- Direct controller no longer depends on PPO/RSL-RL wrapper or checkpoint loading.
- Task registration uses a callable `EasyUUVEnv` entrypoint instead of the old hyphenated module string.

Verification:

- New tests fail before implementation and pass after migration.

### 3. Compatibility Layer And Core Imports

Add small compatibility modules:

- `isaaclab_app.py`: only imports `AppLauncher`, safe to import before app startup.
- `isaaclab_compat.py`: imports Isaac Lab 2.x API after app startup, with Isaac Lab 1.x fallback.

Migrate imports in:

- `easyuuv_env.py`
- `assets/easyuuv.py`
- `thruster_dynamics.py`
- `rigid_body_hydrodynamics.py`
- `asymmetric_noise_cfg.py`
- `agents/rsl_rl_ppo_cfg.py`
- `workflows/cli_args.py`

Verification:

- Source-contract tests confirm old imports are removed from the direct path.
- `compileall` passes.

### 4. Task Registration And Direct Controller

Add `easyuuv_task_registration.py` with `register_easyuuv_task()`.

Update `workflows/play_controller.py`:

- Add project root to `sys.path` before importing the app shim.
- Start `AppLauncher`.
- Import compatibility utilities, task registration and logging helpers only after app startup.
- Register `EasyUUV-Direct-v1`.
- Create the raw Gym environment directly.
- Normalize raw environment observations and step returns.
- Keep legacy controller mode and Koopman JSONL logging.

Verification:

- Local source-contract tests pass.
- Server Isaac Gate runs `play_controller.py` and writes JSONL.

### 5. Server Handoff

Push the branch and give the server validation commands:

- Pull branch.
- Run local Python source tests if desired.
- Run Isaac headless rollout.
- Inspect JSONL tail.

Stop point:

- If the server direct rollout writes JSONL, Phase 1.5 is complete and Phase 2 EDMD can start locally.
- If Isaac raises API errors, capture the traceback and patch the smallest compatibility surface needed.
