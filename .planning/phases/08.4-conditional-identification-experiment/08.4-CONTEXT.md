## Provisional pilot gates (not existing D-23 and not performance evidence)

Correctness: bounds/mask/nonfinite/provenance breaches=0; deployed execution matches modeled input/schedule; truthful causal estimator and reset semantics. A contract repair can be correct without error improvement.

Representation investment: compare on identical trajectories and same model family; candidate20/60-step normalizedmacro error reduction≥10%, each-configuration degradation≤5%, direction agrees on at least2/3 validation seeds. Predeclarefit-only normalization and engineering scale for near-zero denominators. These are screening thresholds, not statistical significance or promotion gates.128-step episodes do not prove512-step full rollout.

Model investment: compare nonlinear model against same-representation simple-linear and persistence. Before fresh pilot outcomes are opened, fix a practical non-inferiority margin for "near persistence", required gains on motion-sensitive channels, per-configuration/excitation summaries, fixed and sliding-origin horizons and complete-episode stability; do not treat survival alone as model benefit. Based on the local control-seam assay, check effective PWM/deadzone coverage and actual mechanical parameter realization, not only raw-action amplitude; hold actual physical input comparable across representation comparisons. A single0.1 probe is not a constant-gain calibration. If only linear improves, revise the chosen scientific branch explicitly; if only oracle/future-input-assisted prediction improves, stop formal collection. One pilot round by default; no unbounded lift/PCA/gate adjustments. Extra budget requires stating what missing evidence it would resolve.

Formal gating, sample size and final outcomes are deliberately not finalized before8.3/pilot. Existing numerical gate failures must be diagnosed, not removed for convenience. NO_GO stops formal recollection even if contract implementation succeeded.
