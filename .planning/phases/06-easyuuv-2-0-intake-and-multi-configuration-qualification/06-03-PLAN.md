<feature>
  <name>Strict versioned EasyUUV v2 qualification artifact validator</name>
  <files>workflows/easyuuv_v2_qualification_artifact.py, workflows/validate_easyuuv_v2_qualification.py, tests/test_easyuuv_v2_qualification.py</files>
  <behavior>
Valid server payload with exact eight unique configurations, correct topology, sufficient steps, finite/bounded controls and server versions → status `pass`, CLI exit 0.
Missing, duplicate or extra configuration → reason `configuration_set_mismatch` or `duplicate_configuration`, exit 1.
Wrong thruster_count/mask/rank → topology-specific reason, exit 1.
NaN/Inf or `abs(value)>1.000001` → `nonfinite_control` or `control_out_of_bounds`, exit 1.
Motor vector length != thruster_count → `motor_dimension_mismatch`, exit 1.
`local_contract` artifact used without `--catalog-only` → `server_evidence_required`, exit 1.
`base.steps_completed<64` or other public row `<8` → `insufficient_steps`, exit 1.
  </behavior>
  <implementation>Use a strict JSON loader, explicit top-level/row required fields, injected-or-lazy topology expectations, exact-set checks and deterministic sorted error output.</implementation>
</feature>
