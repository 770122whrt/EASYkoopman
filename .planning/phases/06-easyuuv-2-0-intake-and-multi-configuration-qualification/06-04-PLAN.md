7. Create `workflows/merge_easyuuv_v2_qualification.py` with repeated `--input` paths and required `--output`. Reject duplicate names; require exact eight names; merge actual versions only if identical; validate the in-memory final payload in server mode before atomically replacing the output file.
8. Add Isaac-free tests for the action sequence/mask, output path confinement, duplicate/missing merge, version disagreement and valid eight-row merge. Mock only the per-row input; do not label tests as physics evidence.
