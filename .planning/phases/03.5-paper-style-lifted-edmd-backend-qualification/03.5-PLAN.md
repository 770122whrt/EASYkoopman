## Wave 1: Paper-Lifted Manifest Selection

Files likely to create or modify:

- Create: `workflows/select_paper_lifted_model.py`
- Test: `tests/test_paper_lifted_selection.py`

Implementation idea:

- Read Phase 2.5 `sweep_results.json`.
- Filter candidates where:
  - `model_class == "paper_lifted_edmd"`;
  - `status == "pass"`;
  - no validation divergence.
- Rank by:
  - validation `multi_step_rmse@20`;
  - validation `multi_step_rmse@60`;
  - lower fallback rate if an offline MPC report is available;
  - simpler observable variant if metrics are close.
- Write `paper_lifted_manifest.json`.

Expected command:

```powershell
python workflows\select_paper_lifted_model.py `
  --sweep-results source\results\koopman_phase2_5_verify_20260701_231802\sweep\sweep_results.json `
  --output source\results\koopman_phase3_5\paper_lifted_manifest.json
```

Acceptance:

- Manifest has `model_class = paper_lifted_edmd`.
- Manifest has `gate_status = pass` only for a valid candidate.
- Manifest includes `selection_role = paper_style_comparison_backend`.
- Manifest includes non-empty `known_limitations`.

## Wave 5: Paper-Lifted Isaac Smoke

```bash

  --task EasyUUV-Direct-v1 \
```
